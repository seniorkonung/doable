## F3 · Low — Циферблат и поле времени по-разному определяют 12- и 24-часовой формат

- **Решение:** Устранить
- **Как устранить:** Вариант A: один итоговый формат часов «устройство + локаль». В конец Фазы 4 в tasks.md добавить новую задачу 4.<следующий свободный номер> (после всех существующих задач). Итог: формат часов для дневных выборов определяет одна функция в `lib/src/daily_choice/presentation/details/daily_choice_field_labels.dart`: формат из `MaterialLocalizations.of(context).timeOfDayFormat(alwaysUse24HourFormat: MediaQuery.alwaysUse24HourFormatOf(context))`; 12-часовой, только если этот формат 12-часовой. Лист времени (`daily_choice_time_sheet.dart`) выбирает `TimeDialClock12` или `TimeDialClock24` по этой функции, а не только по `alwaysUse24HourFormatOf`. Поле «Время», подписи групп каталога и доступные названия часов циферблата и дальше используют `dailyChoiceTimeValue` (`TimeOfDay.format`), поэтому все показы совпадают. Пример: русская локаль с выключенным 24-часовым временем показывает 24-часовой циферблат и «18:00»; английская с выключенным — 12-часовой циферблат и «6:00 PM». Существующий тест `daily_choice_sheet_test.dart` (ру-локаль, 24 часа выключены, 12-часовой циферблат) переписать под новое поведение; в `daily_choice_time_sheet_test.dart` подтвердить совпадение формата циферблата и подписей для ru и en при выключенной 24-часовой настройке. Формулировку критерия задачи 4.7 «Формат циферблата следует системной настройке 24-часового времени» уточнить через openspec-update-change до «следует итоговому формату часов устройства и локали». Собственная настройка формата времени в приложении — решение пользователя: делается отдельным будущим изменением, в это изменение (plan.md, спецификации) не добавляется; функция выбора формата должна быть единственной точкой, которую эта настройка позже переопределит. Подписи резервных копий (`backup_descriptions.dart`) уже следуют той же политике и не меняются. Проверка: тесты `test/daily_choice/presentation/details` и `test/daily_choice/presentation/catalog`.

## F4 · Low — `Tabs` допускает переключатель с параметрами полосы, а защищает от этого только `assert`

- **Решение:** Устранить
- **Как устранить:** В конец Фазы 4 в tasks.md добавить новую задачу 4.<следующий свободный номер> (после всех существующих задач и после задачи по F3, если она уже добавлена). Итог: у `Tabs` в `lib/src/design_system/components/tabs.dart` два конструктора: полоса вкладок (параметры `items`, `value`, `onChange`, `label`, `stuck`, `plane`) и `Tabs.toggle(...)` (параметры `items`, `value`, `onChange`, `label`, `minWidth`) без `stuck` и `plane`. Сочетание переключателя с параметрами полосы не компилируется; `assert` на это сочетание удаляется. `minWidth` остаётся только у переключателя, потому что ни одна полоса его не задаёт; полоса использует прежнюю ширину `DoableMetrics.tapMin`. Смысл для диктора (вкладка или нажатая кнопка) следует из выбранного конструктора, публичный параметр `semantics` не нужен потребителю. Вид и поведение существующих вкладок (`intention_details_tabs.dart`, `daily_choice_sheet.dart`) и переключателя AM/PM в `TimeDial` не меняются. Вызов в `lib/src/design_system/components/time_dial.dart` переводится на `Tabs.toggle`. README `Tabs`, если описывает параметры, приводится в соответствие. Ожидаемые файлы: `tabs.dart`, `time_dial.dart`, `test/design_system/tabs_test.dart`, tasks.md. Проверка: `mise exec --no-deps -- flutter test test/design_system/tabs_test.dart test/design_system/time_dial_test.dart` и тесты вызывающих страниц, которые затронуты.

## F5 · Low — У `TimeDial` есть параметры, которые не нужны ни одному вызову

- **Решение:** Устранить
- **Как устранить:** В конец Фазы 4 в tasks.md добавить новую задачу 4.<следующий свободный номер> (после всех существующих задач; выполняется после задачи по F4, так как обе меняют `time_dial.dart`). Итог: у `TimeDial` и его частей нет параметров, которые не нужны текущему вызову. 1) У `_DialButton` построитель больше не принимает `showsFocus` (оба вызова его отбрасывали, кольцо фокуса рисует сама кнопка): параметр становится построителем без аргументов или готовым дочерним виджетом. 2) Публичный параметр `allDayHint` удаляется; доступное название кнопки «Весь день» берётся из `allDayLabel`. Доступные названия часов по-прежнему задаёт потребитель через `hourLabel`. Вызов в `lib/src/daily_choice/presentation/details/daily_choice_time_sheet.dart` перестаёт передавать `allDayHint`. Видимый текст, доступные названия, кольцо фокуса и поведение циферблата не меняются. Тесты `test/design_system/time_dial_test.dart` обновляются только там, где передавали удалённый параметр. Ожидаемые файлы: `lib/src/design_system/components/time_dial.dart`, `daily_choice_time_sheet.dart`, `test/design_system/time_dial_test.dart`, tasks.md. Проверка: `mise exec --no-deps -- flutter test test/design_system/time_dial_test.dart test/daily_choice/presentation/details`.

## F6 · Low — Тест подтверждения создания проверяет отказ по полю даты, которого система не порождает

- **Решение:** Устранить
- **Как устранить:** Вариант A (узкий). В конец Фазы 4 в tasks.md добавить новую задачу 4.<следующий свободный номер> (после всех существующих задач). Итог: из `test/daily_choice/presentation/editor/daily_choice_creation_page_test.dart` удаляется тест «отказ по полю даты показан уведомлением отказа страницы», который подставляет `DailyChoiceValidationFailure(DailyChoiceValidationField.date)`: ни команда, ни репозиторий такой отказ не порождают, а общий путь уведомления отказа покрыт остальными тестами страницы. Из критерия приёмки задачи 4.11 через openspec-update-change убирается фраза «Отказ команды по полю даты показывается уведомлением отказа страницы, как прочие отказы.». Производственный код, значение `DailyChoiceValidationField.date`, строка `dailyChoiceDateInvalid`, тесты модели создания и презентера не меняются: удаление недостижимого типа `DailyChoiceValidationFailure` целиком существовало до этого изменения и при необходимости делается отдельным изменением. Ожидаемые файлы: `daily_choice_creation_page_test.dart`, tasks.md. Проверка: `mise exec --no-deps -- flutter test test/daily_choice/presentation/editor`.
