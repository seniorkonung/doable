## F2 · Medium — Общее состояние просмотра связи объявляет собственное удаление всем панелям этой связи

- **Решение:** Устранить
- **Как устранить:** Вариант 1, выбран пользователем явно: общая модель RelationDetailsViewModel с ключом relationId остаётся, а право показать прежнее содержимое при закрытии после собственного удаления получает только экземпляр панели, начавший удаление (например, панель передаёт в delete() свой непрозрачный идентификатор, и он хранится в RelationDetailsOwnDeletionConfirmed). Отдельная модель на каждую панель отклонена. Добавить в конец Фазы 3 tasks.md задачу 3.23 после всех существующих; другие фазы и plan.md не менять. Критерии: (1) любая другая открытая панель той же связи после подтверждённого удаления показывает «Эта связь больше не существует.» при любом порядке снимка без связи, пакета завершений и исхода команды, сама не закрывается, параметры недоступны; (2) поведение 3.19 для инициатора не меняется: закрытие без «не найден» в кадрах, перекрытая панель при возврате показывает «не найден», при отказе остаётся открытой с отказом, «Связь удалена» один раз; (3) закрытые типы с исчерпывающим разбором, без флага рядом с прежними состояниями; (4) спецификации и design.md не меняются; (5) новый тест в relation_details_sheet_test.dart открывает две панели одной связи (вторую поверх страницы участника), удаляет связь из верхней и в обоих порядках событий проверяет закрытие верхней с прежним содержимым и «не найден» в нижней после возврата.
