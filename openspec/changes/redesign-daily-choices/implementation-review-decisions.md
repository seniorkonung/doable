Файл ведёт оркестратор. Решения приняты пользователем в сессии решений и исполняются автономно, по одной finding за сессию. Сессия исполнения удаляет раздел своей finding в коммите её устранения.

## F3 · Low — Проверка перезапуска больше не связывает строку с выбранным днём

- **Решение:** Устранить
- **Как устранить:** Устранить заменой проверки, поведение продукта не меняется. Итог: в test/app/daily_choice_app_lifecycle_test.dart проверки порядкового ключа daily-choice-row-1 (строки 765-768 и 788-791) заменяются проверкой ключа daily-choice-completion-<id> с каноническим идентификатором сохранённого выбора этого дня, например через durabilityUuid: для нового сегодня (_nextTodayChoice), прошлого (_pastChoice) и будущего дня (_futureChoice). Тогда тест через интерфейс подтверждает, что показана строка именно выбора этого дня. Дату в карточку не возвращать: спецификация запрещает её там показывать. Остальные ожидания теста не ослаблять. Производственный код, спецификация и design не меняются. Работа: новая задача 1.17 в конце Фазы 1, после задачи F2. Ожидаемые файлы: tasks.md, test/app/daily_choice_app_lifecycle_test.dart.

## F4 · Low — Два теста компонентов не ловят отдельной регрессии

- **Решение:** Устранить
- **Как устранить:** Устранить удалением лишних тестов, поведение продукта не меняется. Итог: удалить тест «название потребителя заменяет прежнее» в test/design_system/scroll_top_button_test.dart (строка 103) вместе со ставшим ненужным параметром label у вспомогательной _app, сохранив константу _label для остальных тестов; удалить тест «выбор без выполнения не рисует галочку» в test/design_system/choice_check_test.dart (строка 81). Остальные тесты этих файлов не менять. Если после удаления остаются неиспользуемые импорты, убрать их. Производственный код, спецификация и design не меняются. Работа: новая задача 1.18 в конце Фазы 1, последней из новых задач, после задачи F3. Её проверка завершается полным mise run check, потому что это последняя задача фазы. Ожидаемые файлы: tasks.md, test/design_system/scroll_top_button_test.dart, test/design_system/choice_check_test.dart.
