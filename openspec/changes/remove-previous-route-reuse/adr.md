# ADR Review Manifest

- Status: completed

## Review Summary

ADR-review завершён. [design.md](design.md) согласован с применимыми принятыми решениями и учитывает связанные предложения. Удаление подсказок сокращает существующие контракт, представление и схему, сохраняя владельцев данных, команд, сообщений и навигации. Новых долговременных архитектурных обязательств не возникает; новый ADR не создан.

Правка схемы версии 1 на месте соответствует подтверждённому пользователем отсутствию установок, требующих перехода со старой схемы. Это условие данного изменения: общий контракт версионирования, проверки снимка схемы и запрет разрушительного восстановления базы сохраняются. Неразрешённых архитектурных решений и противоречий с дизайном нет. Принятые ADR и записи других изменений не редактируются; владение и статусы не меняются.

## Key ADRs for This Change

- [ADR-0009 — единый модуль личного графа и ревизия](../../../docs/adr/0009-unify-personal-graph-module-and-revision.md), **accepted** — применимое ограничение. Удаление `getChoicePathSuggestions` сокращает интерфейс `PersonalGraphRepository`; общие проверки пути, атомарные команды и согласование остаются внутри существующей границы. Для неё действует ADR-0009, заменивший ADR-0005.
- [ADR-0002 — SQLite через Drift](../../../docs/adr/0002-use-drift-sqlite-for-local-graph.md), **accepted** — применимое ограничение хранения. Удаляются два индекса и обновляется снимок единственной схемы; технология, настройка соединений, транзакции и защита пользовательской базы сохраняются.
- [ADR-0022 — завершение создания в собственных границах маршрутов](../../../docs/adr/0022-complete-creation-flows-within-owned-route-boundaries.md), **proposed**; Originating change: `add-quick-creation-and-persistent-navigation` — контекст существующего завершения создания, а не принятое ограничение. Удаление ветвей `previewRoute` сохраняет принадлежность страниц потоку, исходную историю и независимую жизнь принятой команды. Запись принадлежит другому изменению.
