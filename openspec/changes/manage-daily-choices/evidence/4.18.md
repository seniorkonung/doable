# Измерение полного цикла подсказок — задача 4.18

## Среда и набор данных

Измерение выполнено 25 сентября 2026 года на Linux 7.0.0-31-generic x86_64, 8 доступных процессорах, Flutter 3.47.1, Dart 3.13.1 и SQLite 3.53.4. База SQLite находилась в памяти; запросы наблюдались закрытым `LocalDatabaseConnectionObserver`. Команда: `mise exec --no-deps -- flutter test test/graph/data/drift_daily_choice_read_cost_test.dart --plain-name 'полный цикл подсказки измеряет актуализацию, повтор, замену и очередь команд' -r expanded`. Время включает работу репозитория и проверки сохранённого пути, но не построение интерфейса.

До операций сохранены 551 дневной выбор: 401 у одного исходного намерения, включая 400 повторов короткого маршрута и один путь из 150 шагов; ещё 150 выборов относятся к другому действию. Граф содержит 153 намерения и 298 долговременных связей, включая обратные рёбра. Верхняя выдача содержит два различных маршрута, нижняя — один. Лимит отбора — 20 последних записей участника до устранения повторов; лимит выдачи — пять маршрутов.

## Трассировка и планы SQLite

- Для каждого направления и повторной актуализации трасса содержит один индексный отбор максимум 20 кандидатов, 20 точечных чтений дневных выборов и 20 чтений их шагов. Верхнее чтение проверило 169 шагов: 150 у длинного пути и 19 у коротких записей. Все 150 шагов длинного пути опубликованы в подсказке. Ограничения 20/5 не сокращают глубину и не устраняют стоимость проверки каждого выбранного кандидата.
- `EXPLAIN QUERY PLAN` верхнего отбора: `SEARCH daily_choices USING INDEX daily_choices_source_recent (source_intention_id=?)`. Нижнего отбора: `SEARCH daily_choices USING INDEX daily_choices_selected_recent (selected_intention_id=?)`. Чтения намерений выполняются по `WHERE id`, долговременных связей — по `WHERE id IN`; полного чтения истории и графа в трассе нет. Запросов `WITH RECURSIVE` для подсказок нет, простые пути не перечисляются.
- Повторный bootstrap файловой базы с теми же 551 выборами не выполнил чтений таблиц дневных выборов, шагов, намерений и долговременных связей. После завершения чтения подсказок отдельный `BEGIN IMMEDIATE` успешно открылся: транзакция не удерживается между действиями пользователя.
- На настроенном рабочем SQLite isolate запрос длительностью 90,157 мс оставил цикл основного isolate активным: он выполнил 89 тактов таймера. Производственное соединение создаётся через `driftDatabase`, который на Android использует `NativeDatabase.createBackgroundConnection`; проверка подтверждает свойство изолированной схемы исполнения, но не измеряет кадры Android-приложения.
- При 99 последовательных обновлениях модели уже выполнявшееся чтение не размножается в очередь: остаётся один ожидающий запрос. Поздний ответ не делает прежнюю подсказку доступной для подтверждения.

## Безопасность диагностики

Тесты проверили типизированные этапы отбора подсказок, проверки сохранённого пути, создания и замены при успехе. Управляемые отказы на этапе отбора и чтения пути дают категорию `unexpected` с соответствующим этапом; архивирование предложенной связи даёт `conflict` на проверке замены. Сериализованные события содержат только разрешённые поля операции, типа команды, этапа, результата, категории и длительности. Проверены отсутствие пользовательского текста, даты, идентификаторов, маршрута, фильтров, параметров SQL и исходного исключения. Получатель диагностики, выбрасывающий исключение, не меняет успешное чтение, создание, замену или предметный конфликт.
