# Проверка расчёта продолжений пути: задача 2.3

Дата: 2026-09-24. Основа реализации: `6c18024ef95b78097553e9f444c5a6ea13a8c649`.

## Корректность

- Реальный `DriftPersonalGraphRepository` совпал с независимым перебором простых путей на 12 малых графах. Проверены циклы, тупики, возврат в посещённый префикс, архивные связи и намерения, действие на промежуточном шаге, порядок и конфликты снимка.
- Цепочка из 1100 переходов и замыкающая её связь проверяют отсутствие произвольного ограничения глубины.
- Разветвлённый граф из 1900 намерений и 5573 долговременных связей содержит 120 ведущих к действию ветвей и отдельный недостижимый цикл. Обход порциями по 7 и по 100 вернул один и тот же упорядоченный набор из 120 ветвей; цикл не попал в ответ.
- Трассировка всех SQL-чтений при этих обходах показала не более 101 строки на один запрос. Два рекурсивных запроса для порции 100 вернули 101 и 20 строк; предел 101 включает дополнительную строку для признака следующей порции. Полный граф в Dart не переносился. План SQLite содержит рекурсивный набор `reachable`, поиск обратных связей по индексу `long_term_relations_related_group_order` и поиск исходящих связей по индексу `sqlite_autoindex_long_term_relations_2`. Запрос хранит вершины с `UNION`, не перечисляет пути.

## Стоимость

Среда: Linux 7.0.0-31-generic, x86_64, Intel Core i5-9300H 2,40 ГГц, 8 логических процессоров; Flutter 3.47.1, Dart 3.13.1, SQLite 3.53.4. Измерения получены командой:

`mise exec --no-deps -- flutter test --no-pub test/daily_choice/application/choice_path_continuations_test.dart test/graph/data/drift_choice_path_continuations_test.dart --reporter expanded`

| Сценарий | Результат |
| --- | ---: |
| Весь обход 120 ветвей порциями по 7, 18 страниц | 219 277 мкс |
| Весь обход порциями по 100, 2 страницы | 32 316 мкс |
| Рекурсивный SQL для двух страниц по 100 | 9 216 и 9 208 мкс |
| Чтение первой страницы перед следующей командой | 12 286 мкс |
| Следующая команда в общей очереди, от вызова до ответа | 20 204 мкс |
| Аналогичная команда без предшествующего чтения | 1 547 мкс |
| Чтение через отдельный изолят: 4000 намерений, 11 955 связей | 25 233 мкс |

Команда в очереди завершилась успешно после чтения; разность её полного времени и отдельной команды показывает стоимость ожидания вместе с накладными расходами планировщика, но не является точным временем ожидания. В тесте с изолятом событие основного цикла было обработано до завершения рекурсивного запроса. Производственное соединение создаётся через `driftDatabase` из `drift_flutter` 0.3.1; установленная реализация использует `NativeDatabase.createBackgroundConnection` для обычного режима. Это подтверждает вынесение SQLite-работы из UI isolate на используемом пути соединения.

Числа зависят от машины и нагрузки, поэтому тест утверждает предметные результаты и объём передачи данных, но не содержит нестабильного порога времени. Повторный замер выполняется той же командой. Проверка OpenSpec: `mise exec --no-deps -- openspec validate manage-daily-choices --strict --no-interactive` — успешно.
