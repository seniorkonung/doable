# ADR Review Manifest

- Status: completed
- Review date: 2026-10-12

## Review Summary

Обзор завершён. После согласования [design.md](design.md) соответствует применимым принятым ADR и трём новым предложениям.

- **ADR-0026** закрепляет подсчёт вида «Через связи» по опорным намерениям выбора и достижимости в снимке активных связей. Доказательство достаточности исходного опорного набора и группировка по нему применяются к полному активному графу. Для разбивки по связям с исключённым намерением эта эквивалентность не переносится автоматически: отдельный набор оснований, его достаточность и группировка определены в решении 3 [дизайна](design.md). Это уточнение области применения ADR-0026 действует для данного изменения; оно не меняет правила засчитывания спецификации. Снимок живёт в памяти адаптера до изменения связей, подсчёт идёт в фоновом изоляте вне общей очереди, а при чтении названий сверяется ревизия. Принятую ADR-0011 запись не заменяет: та ограничивает только счётчики связей.
- **ADR-0027** вводит для статистики обновление только при показе вместо перечитывания после каждой ревизии. Отметки дней по-прежнему согласуются по ADR-0024.
- **ADR-0028** привязывает состояние, заданное параметрами открытия страницы (дата каталога, цель статистики), к экземпляру страницы. Границы владения ADR-0017 и ADR-0025 сохраняются внутри каждого экземпляра каталога.

При согласовании решения 3–6 и 8 дизайна получили ссылки на новые ADR. Агрегаты по сохранённому пути с ключевой пагинацией применяют уже принятый подход ADR-0011 и ADR-0024 и отдельной записи не требуют. Не создают долговременной границы и остаются в дизайне и спецификациях: контракт чтения внутри `PersonalGraphRepository`, тип цели перехода, размер порций, диагностика и бюджеты замера.

В `CONTEXT.md` добавлены термины «Промежуточное намерение», «Вид статистики», «Запланированный вклад» и «Вклад». «Период статистики» в глоссарий не вошёл: это календарный месяц или год без особого предметного смысла. «Опорные намерения» — понятие подсчёта, оно описано в ADR-0026 и дизайне.

Навыка `grill-with-docs`, которого требует правило проекта, в этой среде нет. Существенных нерешённых архитектурных решений не осталось: бюджеты замера зафиксированы в дизайне как предложение и проверяются владельцем вместе с артефактами.

ADR review completed. Owned ADRs remain proposed and editable until archival;
accepted ADRs are immutable.

## Key ADRs for This Change

- [ADR-0009 — Личный граф и ревизия](../../../docs/adr/0009-unify-personal-graph-module-and-revision.md) — `accepted`, обязательное ограничение. Единственная граница `PersonalGraphRepository`, ограниченные порции на границе, последовательный исполнитель, общая ревизия и отбрасывание устаревших ответов. Подсчёт вне очереди остаётся внутренней композицией за этой границей.
- [ADR-0011 — Счётчики связей из снимков](../../../docs/adr/0011-derive-relation-counts-from-graph-snapshots.md) — `accepted`. Прецедент агрегатов без хранимых счётчиков и без ложного нуля. Запрет загружать списки связей в Dart действует для счётчиков; отличие снимка ADR-0026 объяснено в её контексте.
- [ADR-0024 — Состояния дней агрегатом](../../../docs/adr/0024-derive-calendar-day-states-from-saved-daily-choices.md) — `proposed`; Originating change: `add-daily-choice-calendar-day-marks` (архивировано). Прецедент агрегата для видов по сохранённому пути. Политика перечитывания после каждой ревизии остаётся за отметками; статистика следует ADR-0027.
- [ADR-0025 — Отдельная модель отметок](../../../docs/adr/0025-load-calendar-day-marks-in-separate-viewport-model.md) — `proposed`; Originating change: `add-daily-choice-calendar-day-marks` (архивировано). Модель отметок живёт со страницей каталога; по ADR-0028 — со своим экземпляром каталога.
- [ADR-0017 — Компонент календаря](../../../docs/adr/0017-isolate-inline-calendar-behind-app-component.md) — `proposed`; Originating change: `add-inline-daily-choice-calendar` (архивировано). Владение выбранной датой и просмотром сохраняется внутри каждого экземпляра каталога. Календарь раздела статистики — отдельная сетка, а не этот компонент.
- [ADR-0002 — Drift и SQLite](../../../docs/adr/0002-use-drift-sqlite-for-local-graph.md) — `accepted`. Одно соединение в фоновом изоляте без WAL; поэтому отвергнуто отдельное соединение для чтения статистики. Фоновый изолят подсчёта к хранилищу не обращается.
