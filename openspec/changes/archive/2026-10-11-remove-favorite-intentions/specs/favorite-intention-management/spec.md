## REMOVED Requirements

### Requirement: Отметка избранного намерения
**Reason**: Концепция избранности намерений удаляется из продукта.

**Migration**: Отметка удаляется из данных, черновика создания и управления намерением.

### Requirement: Единый ручной порядок избранных намерений
**Reason**: Концепция избранности намерений удаляется из продукта.

**Migration**: Ручной порядок избранных удаляется из хранения и прикладных контрактов без замены другим порядком намерений.

### Requirement: Список избранных намерений на Главной
**Reason**: Концепция избранности намерений удаляется из продукта.

**Migration**: Главная становится пустой корневой страницей по обновлённой `app-navigation`.

### Requirement: Избранное намерение при архивировании и восстановлении
**Reason**: Концепция избранности намерений удаляется из продукта.

**Migration**: Архивирование и восстановление действуют по `intention-management` без состояния избранности.

### Requirement: Перестановка избранных намерений на Главной
**Reason**: Концепция избранности намерений удаляется из продукта.

**Migration**: Перестановка и её действия удаляются вместе со списком.

### Requirement: Пустые состояния Главной
**Reason**: Концепция избранности намерений удаляется из продукта.

**Migration**: Пустая область содержимого Главной определяется `app-navigation`; объяснения отсутствия избранных и переход из списка удаляются.

### Requirement: Получение списка Главной и безопасные ошибки
**Reason**: Концепция избранности намерений удаляется из продукта.

**Migration**: Чтение списка, его загрузка, ошибки и повтор удаляются из Главной.

### Requirement: Согласованность Главной с подтверждёнными изменениями
**Reason**: Концепция избранности намерений удаляется из продукта.

**Migration**: Главная больше не содержит данных намерений для согласования; правила остальных представлений остаются у их возможностей.

### Requirement: Атомарность и согласованность операций избранного
**Reason**: Концепция избранности намерений удаляется из продукта.

**Migration**: Команды отметки, снятия отметки и перестановки удаляются из прикладной границы.

### Requirement: Локальное сохранение избранных намерений
**Reason**: Концепция избранности намерений удаляется из продукта.

**Migration**: Таблица и остальные объекты поддержки избранного удаляются из текущей схемы SQLite версии 1. Перенос старых баз не предоставляется; перед запуском новой сборки пользователь самостоятельно очищает прежние локальные данные. Приложение не удаляет и не пересоздаёт их автоматически.

### Requirement: Локализация и доступность избранного
**Reason**: Концепция избранности намерений удаляется из продукта.

**Migration**: Системные строки, подсказки и семантика удаляемых элементов исчезают вместе с ними; общие правила локализации и доступности продолжают действовать для оставшегося интерфейса.

### Requirement: Диагностика операций избранного без данных личного графа
**Reason**: Концепция избранности намерений удаляется из продукта.

**Migration**: События и этапы диагностики избранного удаляются; общая граница диагностики сохраняется для остальных операций.
