## MODIFIED Requirements

### Requirement: Локальная долговечность данных приложения
Система MUST сохранять подтверждённые данные между полными перезапусками и совместимыми обновлениями в пределах одной установки приложения; это относится и к резервным копиям по `graph-backups`. Каждый поддерживаемый platform adapter MUST исключать локальное хранилище, его служебные файлы и файлы резервных копий из системного cloud backup и переноса данных между устройствами. После удаления приложения, очистки его данных или утраты устройства система SHALL NOT восстанавливать прежние данные в новой установке автоматически и SHALL NOT представлять прежние резервные копии доступными: вернуть данные можно только явным импортом файла экспорта по `graph-export-import`. Экспорт и импорт файла определяет `graph-export-import`, резервные копии — `graph-backups`; удалённое хранение и синхронизация данных не входят в эту capability.

#### Scenario: Сохранение данных после полного перезапуска
- **GIVEN** пользователь подтвердил изменения локальных данных приложения
- **WHEN** приложение полностью завершается и запускается снова в той же установке
- **THEN** система восстанавливает последнее подтверждённое состояние данных

#### Scenario: Исключение данных из облачной резервной копии
- **GIVEN** поддерживаемая платформа выполняет системный cloud backup данных приложения
- **WHEN** система применяет правила резервного копирования Doable
- **THEN** локальное хранилище, его служебные файлы и файлы резервных копий не включаются в облачную резервную копию

#### Scenario: Исключение данных из переноса между устройствами
- **GIVEN** поддерживаемая платформа выполняет системный перенос данных на новое устройство
- **WHEN** система применяет правила переноса данных Doable
- **THEN** локальное хранилище, его служебные файлы и файлы резервных копий не переносятся в новую установку

#### Scenario: Отсутствие восстановления после утраты установки
- **GIVEN** прежняя установка Doable удалена, её данные очищены либо устройство утрачено
- **WHEN** пользователь запускает новую установку без существующего локального хранилища
- **THEN** система начинает работу без прежних данных и резервных копий и не восстанавливает их сама, а импорт файла экспорта доступен
