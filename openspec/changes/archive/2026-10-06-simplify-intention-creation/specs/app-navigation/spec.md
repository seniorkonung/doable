## MODIFIED Requirements

### Requirement: Панель только на корневых страницах
Корневыми страницами являются Главная, каталог дневных выборов и каталог намерений, открытые пунктами панели. Панель MUST быть видна на каждой корневой странице, когда её не перекрывает модальная нижняя панель создания намерения, и MUST NOT быть видна ни на какой другой странице. Страница намерения, подробный просмотр долговременной связи и дневного выбора, формы создания других сущностей и изменения, выбор действия, исходного намерения, участника связи и пути, каталог тегов, навигация по тегу и остальные страницы SHALL открываться поверх корневой страницы на весь экран и закрывать панель. Каталог намерений, открытый как поиск действия, исходного намерения или участника связи, корневой страницей не является. Пока поверх корневой страницы открыта другая страница, смена пункта MUST быть недоступна. Закрытие всех открытых поверх страниц MUST возвращать пользователя на ту корневую страницу, с которой был начат переход, с тем же выбранным пунктом.

Состояния загрузки и отказа подготовки локального хранилища по `local-data-lifecycle` MUST показываться без панели и корневых страниц.

Форма создания намерения SHALL быть исключением из полноэкранного открытия форм: из корневого каталога она MUST открываться модальной нижней панелью по `intention-management` с сохранением корневой страницы под ней. Панель MUST оставаться компактной, с видимой частью каталога над ней и высотой под содержимое и доступное пространство в пределах действующего ограничения; ручное разворачивание и сворачивание MUST NOT предоставляться. Пока эта панель или открытая из неё страница существуют, взаимодействие с каталогом под ней и смена пункта основной навигации MUST быть недоступны. Общий выбор тегов и редактор тега SHALL открываться над панелью на весь экран без основной навигации. Возвращение из них MUST восстанавливать ту же панель и черновик без повторного открытия формы с высотой под актуальное содержимое и доступное пространство. Закрытие панели по запросу пользователя, с подтверждением в случаях, предусмотренных сессией черновика, MUST возвращать исходный каталог с прежним выбранным пунктом, параметрами и позицией по действующим правилам согласования.

Подтверждённое успешное создание в сохраняющейся исходной сессии формы SHALL закрывать панель и открывать страницу созданного намерения по `intention-management` поверх того же исходного каталога на весь экран без основной навигации. Завершённая панель и её подтверждение ухода MUST NOT оставаться в истории возврата. Закрытие страницы созданного намерения, в том числе действием «назад», MUST возвращать исходный каталог с прежним выбранным пунктом, параметрами и позицией по действующим правилам согласования. Успех после подтверждённого ухода из исходной сессии MUST NOT открывать страницу намерения или менять текущую страницу по `intention-management`.

Если отказ открытия страницы уже созданного намерения оставил исходную панель в стеке, её обычные способы закрытия MUST оставаться доступны по `intention-management`. Новый запрос закрытия MUST удалять только эту панель и её неактуальное подтверждение ухода и возвращать исходный каталог с прежним выбранным пунктом, параметрами и позицией по действующим правилам согласования, без подтверждения потери уже сохранённых данных. Восстановление выхода MUST NOT удалять оболочку, страницу намерения либо другую или заново открытую форму. После ухода завершённая панель и её диалог MUST NOT оставаться в истории возврата.

#### Scenario: Страница намерения закрывает панель
- **GIVEN** Главная показывает избранное намерение
- **WHEN** пользователь открывает его страницу
- **THEN** страница намерения занимает весь экран, панель не видна и сменить пункт нельзя

#### Scenario: Возврат на корневую страницу начала перехода
- **GIVEN** пользователь с Главной открыл страницу намерения, а из неё — подробный просмотр его связи
- **WHEN** он закрывает обе страницы
- **THEN** открыта Главная с выбранным пунктом «Главная» и видимой панелью

#### Scenario: Поиск действия не является корневой страницей
- **GIVEN** пользователь создаёт дневной выбор из каталога дневных выборов
- **WHEN** открыт поиск действия
- **THEN** поиск занимает весь экран без панели, а его закрытие возвращает в каталог дневных выборов с выбранным пунктом «Дневные выборы»

#### Scenario: Отказ подготовки хранилища показан без панели
- **WHEN** подготовка локального хранилища завершается отказом
- **THEN** пользователь видит состояние отказа по `local-data-lifecycle` без панели и корневых страниц

#### Scenario: Создание открывается поверх исходного каталога
- **GIVEN** выбран пункт «Граф намерений» и открыт его корневой каталог
- **WHEN** пользователь нажимает «+» для создания намерения
- **THEN** над сохранённым каталогом открыта компактная модальная нижняя панель без ручного разворачивания, а каталог и смена пункта под ней недоступны для взаимодействия

#### Scenario: Общий выбор тегов открывается над панелью
- **GIVEN** панель создания содержит заполненный черновик
- **WHEN** пользователь открывает общий выбор тегов
- **THEN** выбор занимает весь экран без основной навигации, а сессия панели и её черновик сохраняются

#### Scenario: Общий выбор тегов возвращает ту же панель
- **GIVEN** общий выбор тегов открыт над панелью с заполненным черновиком
- **WHEN** пользователь закрывает выбор тегов
- **THEN** показана та же компактная панель с сохранённым черновиком и выбранным пунктом «Граф намерений»

#### Scenario: Страница созданного намерения открывается поверх каталога
- **GIVEN** выбран пункт «Граф намерений», а исходная сессия создания остаётся открытой над каталогом
- **WHEN** создание успешно завершается
- **THEN** панель закрывается и страница созданного намерения занимает весь экран без основной навигации, а сменить пункт нельзя

#### Scenario: Возврат после создания не открывает завершённую форму
- **GIVEN** после успешного создания автоматически открыта страница нового намерения, а исходный каталог был прокручен и использовал охват, фильтр названия и условия по тегам, которым новое намерение не соответствует
- **WHEN** пользователь выполняет действие «назад» на странице намерения
- **THEN** открыт исходный каталог с выбранным пунктом «Граф намерений», прежними параметрами и позицией, а завершённая форма и её подтверждение ухода не показываются
- **AND** новое намерение не включено в неподходящую выдачу

#### Scenario: Закрытие после отказа открытия возвращает сохранённый каталог
- **GIVEN** каталог был прокручен и использовал охват, фильтр названия и условия по тегам, которым созданное намерение не соответствует, а отказ открытия его страницы оставил исходную панель в стеке
- **WHEN** пользователь закрывает оставшуюся панель кнопкой закрытия или системным «назад»
- **THEN** открыт исходный каталог с выбранным пунктом «Граф намерений», прежними параметрами и позицией, без завершённой панели и её подтверждения ухода в истории
- **AND** созданное намерение не включено в неподходящую выдачу, а смена пункта и новое создание снова доступны
