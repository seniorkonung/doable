## MODIFIED Requirements

### Requirement: Панель только на корневых страницах
Корневыми страницами являются Главная, каталог дневных выборов и каталог намерений, открытые пунктами панели. Панель MUST быть видна на каждой корневой странице, когда её не перекрывает модальная нижняя панель создания намерения, и MUST NOT быть видна ни на какой другой странице. Страница намерения, подробный просмотр долговременной связи и дневного выбора, формы создания других сущностей и изменения, выбор действия, исходного намерения, участника связи и пути, каталог тегов, навигация по тегу и остальные страницы SHALL открываться поверх корневой страницы на весь экран и закрывать панель. Каталог намерений, открытый как поиск действия, исходного намерения или участника связи, корневой страницей не является. Пока поверх корневой страницы открыта другая страница, смена пункта MUST быть недоступна. Закрытие всех открытых поверх страниц MUST возвращать пользователя на ту корневую страницу, с которой был начат переход, с тем же выбранным пунктом.

Состояния загрузки и отказа подготовки локального хранилища по `local-data-lifecycle` MUST показываться без панели и корневых страниц.

Форма создания намерения SHALL быть исключением из полноэкранного открытия форм: из корневого каталога она MUST открываться модальной нижней панелью по `intention-management` с сохранением корневой страницы под ней. Начальный режим MUST быть компактным, с видимой частью каталога над панелью и высотой под содержимое и доступное пространство; явное разворачивание на весь доступный экран MUST менять только размер этой же панели без перехода на другую страницу. Пока эта панель или открытая из неё страница существуют, взаимодействие с каталогом под ней и смена пункта основной навигации MUST быть недоступны. Общий выбор тегов и редактор тега SHALL открываться над панелью на весь экран без основной навигации. Возвращение из них MUST восстанавливать ту же панель, её режим и черновик без повторного открытия формы. Окончательное закрытие панели MUST возвращать исходный каталог с прежним выбранным пунктом, параметрами и позицией по действующим правилам согласования.

#### Scenario: Страница намерения закрывает панель
- **GIVEN** Главная показывает избранное намерение
- **WHEN** пользователь открывает его страницу
- **THEN** страница намерения занимает весь экран, панель не видна и сменить пункт нельзя

#### Scenario: Возврат на корневую страницу начала перехода
- **GIVEN** пользователь с Главной открыл страницу намерения, а из неё — подробный просмотр его связи
- **WHEN** он закрывает обе страницы
- **THEN** открыта Главная с выбранным пунктом «Главная» и видимой панелью

#### Scenario: Поиск действия не является корневой страницей
- **GIVEN** пользователь создаёт дневной выбор из каталога дневных выборов
- **WHEN** открыт поиск действия
- **THEN** поиск занимает весь экран без панели, а его закрытие возвращает в каталог дневных выборов с выбранным пунктом «Дневные выборы»

#### Scenario: Отказ подготовки хранилища показан без панели
- **WHEN** подготовка локального хранилища завершается отказом
- **THEN** пользователь видит состояние отказа по `local-data-lifecycle` без панели и корневых страниц

#### Scenario: Создание открывается поверх исходного каталога
- **GIVEN** выбран пункт «Граф намерений» и открыт его корневой каталог
- **WHEN** пользователь нажимает «+» для создания намерения
- **THEN** над сохранённым каталогом открыта модальная нижняя панель, а каталог и смена пункта под ней недоступны для взаимодействия

#### Scenario: Общий выбор тегов открывается над панелью
- **GIVEN** панель создания содержит заполненный черновик
- **WHEN** пользователь открывает общий выбор тегов
- **THEN** выбор занимает весь экран без основной навигации, а сессия панели и её черновик сохраняются

#### Scenario: Общий выбор тегов возвращает ту же панель
- **GIVEN** общий выбор тегов открыт над панелью с заполненным черновиком
- **WHEN** пользователь закрывает выбор тегов
- **THEN** показана та же панель с сохранённым черновиком и выбранным пунктом «Граф намерений»

### Requirement: Действие «назад» на корневых страницах
Системное действие «назад» на каталоге дневных выборов и на каталоге намерений как корневых страницах, когда поверх них нет открытой страницы или панели создания намерения, MUST выбирать пункт «Главная» и сохранять состояние покинутой страницы. На Главной системное действие «назад» MUST покидать приложение по правилам платформы. На странице, открытой поверх корневой, действие «назад» SHALL закрывать только эту страницу по её собственным правилам и MUST NOT менять выбранный пункт.

В открытой нижней панели создания намерения запрос закрытия по действию «назад» MUST обрабатываться правилами черновика из `intention-management` и MUST NOT менять выбранный пункт основной навигации. Если действие сначала скрывает клавиатуру по правилам платформы, оно MUST сохранять панель и черновик. В общем выборе тегов или редакторе, открытых из панели, «назад» SHALL закрывать только текущую страницу по её собственным правилам; закрытие выбора MUST возвращать панель, а не закрывать её вместе с выбором.

#### Scenario: «Назад» с каталога намерений ведёт на Главную
- **GIVEN** выбран пункт «Граф намерений» и поверх каталога намерений нет открытых страниц или панели создания намерения
- **WHEN** пользователь выполняет системное действие «назад»
- **THEN** открыта Главная с выбранным пунктом «Главная», а параметры и позиция каталога намерений сохранены

#### Scenario: «Назад» на Главной покидает приложение
- **GIVEN** выбран пункт «Главная» и поверх Главной нет открытых страниц
- **WHEN** пользователь выполняет системное действие «назад»
- **THEN** приложение покидается по правилам платформы без перехода на другую корневую страницу

#### Scenario: «Назад» закрывает страницу поверх корневой
- **GIVEN** из каталога дневных выборов открыт подробный просмотр дневного выбора
- **WHEN** пользователь выполняет системное действие «назад»
- **THEN** закрывается только подробный просмотр, и открыт каталог дневных выборов с выбранным пунктом «Дневные выборы»

#### Scenario: «Назад» из изменённого черновика запрашивает подтверждение
- **GIVEN** выбран пункт «Граф намерений», клавиатура скрыта, а панель содержит изменённый черновик
- **WHEN** пользователь выполняет действие «назад» для закрытия панели
- **THEN** показано подтверждение потери черновика, а выбранный пункт не меняется

#### Scenario: «Назад» закрывает только выбор тегов
- **GIVEN** общий выбор тегов открыт из панели создания
- **WHEN** пользователь выполняет действие «назад» на странице выбора
- **THEN** закрывается только выбор, а панель и её черновик остаются открыты с выбранным пунктом «Граф намерений»
