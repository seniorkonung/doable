## Phase 1: Полные списки тегов доступны без скачков при выборе

- [x] 1.1 Выбор загруженной строки сохраняет геометрию и прокрутку
  - **Критерии приёмки:** Выбор готов немедленно; постоянная кнопка не меняет размеры списка.
  - **Проверка:** `flutter test --no-pub test/tag/presentation/catalog/tag_catalog_selection_stability_test.dart`.
  - **Зависимости:** Нет.
  - **Вероятные файлы:** каталог, его ViewModel и регрессионный виджетный тест.
  - **Размер:** M.

- [x] 1.2 Контракт графа возвращает полные снимки каталогов и назначений
  - **Критерии приёмки:** Больше 100 тегов доступны целиком на одной ревизии; порядок, ошибки и диагностика сохраняются.
  - **Проверка:** `flutter test --no-pub test/graph/data/drift_tag_read_test.dart test/graph/data/drift_tag_assignment_read_test.dart`.
  - **Зависимости:** 1.1.
  - **Вероятные файлы:** контракты тегов, адаптер Drift, диагностика и тесты чтений.
  - **Размер:** M.

- [x] 1.3 Представления тегов используют полные снимки без продолжений
  - **Критерии приёмки:** Каталог и назначения обновляются без очистки строк; поздние ответы и удаление выбранного тега согласованы.
  - **Проверка:** `flutter test --no-pub test/tag/presentation/catalog test/tag/presentation/assignments`.
  - **Зависимости:** 1.2.
  - **Вероятные файлы:** состояния, ViewModels и представления каталога и назначений.
  - **Размер:** M.

- [x] 1.4 Потребители и проверки соответствуют полным спискам тегов
  - **Критерии приёмки:** Сценарии редактора, долговечности, ошибок и полной выдачи переведены без потери гарантий; навигация остаётся порционной.
  - **Проверка:** `flutter test --no-pub test/tag test/graph/data test/app`.
  - **Зависимости:** 1.3.
  - **Вероятные файлы:** тестовые адаптеры, контрактные, интеграционные и пользовательские тесты.
  - **Размер:** M.

- [x] 1.5 Подтверждена готовность полного изменения
  - **Критерии приёмки:** Анализ, форматирование, тесты и строгая валидация проходят; проверка устройства выполнена либо ограничение явно записано.
  - **Проверка:** `mise run check; openspec validate stabilize-tag-selection --strict; проверка устройства`.
  - **Зависимости:** 1.1, 1.2, 1.3, 1.4.
  - **Вероятные файлы:** Нет, только проверка и фиксация свидетельств.
  - **Размер:** XS.
