Вероятные файлы указаны по текущему репозиторию; сгенерированные производные обновляются вместе с изменённым источником.

Пакет охватывает первую и вторую фазы. Задачи общих контрактов задают возможности для последующих потребителей; прикладной модуль и представления проверяются через эти контракты, а их реальное соединение — отдельными контрольными точками. Схема 6, удаление прежних назначений из базы и проверки всех путей миграции относятся ко второй фазе.
