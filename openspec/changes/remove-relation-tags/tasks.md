Основание: [план](plan.md), [требования тегов](specs/tag-management/spec.md), [связей](specs/long-term-relation-management/spec.md) и [намерений](specs/intention-management/spec.md), [дизайн](design.md) и [проверка ADR](adr.md). Качество проверяется по [Definition of Done](../../../apm_modules/seniorkonung/agent-skills/references/definition-of-done.md). Вероятные файлы указаны по текущему репозиторию; сгенерированные производные обновляются вместе с изменённым источником.

Пакет охватывает первую и вторую фазы. Задачи общих контрактов задают возможности для последующих потребителей; прикладной модуль и представления проверяются через эти контракты, а их реальное соединение — отдельными контрольными точками. Текущая схема без получателя-связи, единственная версия схемы и удаление прежних версий вместе с их проверками относятся ко второй фазе.
