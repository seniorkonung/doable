## Findings

### F1 · Medium — Геометрический возврат во время инерции стирает пользовательскую цель

- **Evidence:** `lib/src/daily_choice/presentation/catalog/daily_choice_catalog_body.dart:267–279` обновляет снимок для любого `ScrollUpdateNotification`, пока `userScrollDirection != idle`. Flutter 3.47.1 сохраняет направление при замене одной `BallisticScrollActivity` другой (`package:flutter/src/widgets/scroll_position_with_single_context.dart:114–125`). После изменения размеров `BallisticScrollActivity.applyNewDimensions` перезапускает симуляцию (`package:flutter/src/widgets/scroll_activity.dart:615–617`). Если текущая позиция выше новой границы, `ClampingScrollPhysics.createBallisticSimulation` запускает возврат к ней, заменяя положительную скорость нулевой (`package:flutter/src/widgets/scroll_physics.dart:895–912`). Уведомления вынужденного возврата проходят новый пользовательский предикат и перезаписывают снимок; `daily_choice_catalog_body.dart:284–302` восстанавливает уже уменьшенную цель. Новый тест `test/daily_choice/presentation/catalog/daily_choice_catalog_layout_test.dart:111–128` полностью завершает инерцию через `pumpAndSettle` до следующего движения ручки. Координатор воспроизвёл пересечение без изменения кода репозитория: при скорости +250 dp/с дальнейшее движение ручки уменьшило диапазон ниже текущей позиции; после возврата корневой каталог сохранил 2321 вместо 2341 dp, каталог на дату — 2377 вместо 2397 dp. Потеря 20 dp подтверждена и для отпускания, и для системной отмены.
- **Evidence revisions:** ["807befda594d91449200f7e6d9e4c4e5435b196c"]
- **Impact:** Достижимая последовательность: удерживать ручку после небольшого сворачивания → вторым указателем прокрутить выдачу к концу и отпустить с инерцией → до её окончания продолжить движение той же ручки, уменьшив диапазон ниже текущего смещения → дождаться вынужденного возврата списка → медленно отпустить ручку или отменить жест. Календарь раскрывается, но выдача теряет результат отдельной прокрутки. Общий обработчик затрагивает оба каталога. День, фильтр, выдача и конечное представление не меняются, поэтому их защитные сбросы не помогают. Нарушены delta-spec:16 и решения 4/6 дизайна.
- **Required outcome:** Продолжение движения удерживаемой ручки во время пользовательской инерции не подменяет цель восстановления смещением, вызванным только уменьшением диапазона. Возврат календаря сохраняет результат отдельной прокрутки. Проверка воспроизводит пересечение продолжающейся инерции и изменения высоты.
