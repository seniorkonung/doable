## F2 · Medium — Изменение со страницы, открытой из поиска, сдвигает видимую строку

- **Решение:** Устранить
- **Как устранить:** Исправить в этой ветке новой задачей в конце Phase 1 tasks.md с номером 1.<следующий свободный>; ветку change/redesign-intention-catalog не трогать. Требуемый результат: если подтверждённая операция меняет строки перед видимой, пока поиск закрыт страницей поверх него, после возврата на экране стоит та же первая видимая строка (или ближайший оставшийся сосед), а её место определено по выдаче, которая реально построена и разложена. Способ: ResultsScrollKeeper не расходует запомненный якорь и не восстанавливает место по устаревшей выдаче `_shown()`; якорь хранится, пока список не перестроится по актуальной выдаче, и применяется только после этого, а перестройка при возврате должна запускать восстановление. Новая выдача (новый объект запроса) по-прежнему сбрасывает якорь и начинается с верха, в том числе перезапуск поиска участника по требованию «Отметка занятой пары». Исправление работает для обоих потребителей хранителя: IntentionSearchList и IntentionSearchResults. Исправление применяется ко всем экранам, поэтому через openspec-update-change добавить в plan.md и design.md уточнение инварианта «Общий каталог и поиски дневного выбора ведут себя как прежде»: единственное допустимое изменение для них — удержание места в списке (F2–F4) строго по требованию «Сохранение состояния загруженного каталога»; спецификации не меняются. Регрессионная проверка в test/intention/presentation/search/intention_search_list_test.dart: изменение при закрытом списке, после возврата строка на месте. Завершающая задача: если в implementation-review-decisions.md, кроме этой находки, не осталось других, после своей задачи добавить последнюю задачу Phase 1 — повторить проверки задачи 1.8 (`grep` на `excludedIntentionId`, `mise run check`, `openspec validate --strict`, `mise run codegen-check`, `flutter build apk --release`, ручные проверки). Ожидаемые артефакты: tasks.md, plan.md, design.md, results_scroll_keeper.dart, intention_search_list.dart, intention_search_results.dart, тест выдачи.

## F3 · Medium — Добавление порции останавливает инерцию и обрывает перетаскивание

- **Решение:** Устранить
- **Как устранить:** Вариант А, выбран пользователем; исправлять в этой ветке новой задачей в конце Phase 1 tasks.md с номером 1.<следующий свободный>, после задачи F2, поверх её результата. Требуемый результат: если первая видимая строка не сместилась, хранитель вообще не трогает прокрутку, в том числе при добавлении порции: инерция и перетаскивание продолжаются на границах порций. ResultsScrollKeeper определяет не «изменилась ли выдача», а «могла ли сместиться видимая строка»: добавление строк в конец при неизменном начале якорь не снимает, а восстановление не вызывает `jumpTo`, если строка уже на своём месте. Пользователь осознанно сузил ожидаемый результат отчёта: реальный сдвиг поправляется прежним `jumpTo` и может остановить инерцию, если подтверждение операции пришло, пока человек прокручивает открытый список; поправку без остановки жеста, с вмешательством во внутреннее состояние прокрутки Flutter, не делать. Это обязательное условие решения, а не пробел. Удержание места при вставке перед видимой строкой и переход к верху при новой выдаче не меняются. Регрессионная проверка в test/intention/presentation/search/intention_search_list_test.dart: идущая прокрутка не останавливается добавлением порции, без замеров времени. Завершающая задача: если в implementation-review-decisions.md, кроме этой находки, не осталось других, после своей задачи добавить последнюю задачу Phase 1 — повторить проверки задачи 1.8 (`grep` на `excludedIntentionId`, `mise run check`, `openspec validate --strict`, `mise run codegen-check`, `flutter build apk --release`, ручные проверки). Ожидаемые артефакты: tasks.md, results_scroll_keeper.dart, тест выдачи.

## F4 · Low — Отметка меняет высоту строки, а хранитель этого не учитывает

- **Решение:** Устранить
- **Как устранить:** Исправить в этой ветке новой задачей в конце Phase 1 tasks.md с номером 1.<следующий свободный>, после задач F2 и F3, поверх их результата: без F2 условие не сработает, потому что связь меняется, пока поиск закрыт. Требуемый результат: согласование отметок не сдвигает первую видимую строку, даже если меняется высота другой строки выдачи (линия меток появляется или исчезает у строки без меток и тегов). ResultsScrollKeeper учитывает изменение занимающих связей (`pairOccupants`) наряду с изменением строк как возможный сдвиг видимой строки, сохраняя условие F3: без смещения прокрутку не трогать. `_applyRelationChanges` в модели каталога по-прежнему сохраняет те же объекты `items`, состав, порядок, число совпадений и курсор; проекция строки и линия меток не меняются, резервировать место под метку нельзя. Регрессионная проверка в test/intention/presentation/search/intention_search_list_test.dart: появление или снятие отметки у строки над видимой при закрытом списке не сдвигает первую видимую строку. Завершающая задача: если в implementation-review-decisions.md, кроме этой находки, не осталось других, после своей задачи добавить последнюю задачу Phase 1 — повторить проверки задачи 1.8 (`grep` на `excludedIntentionId`, `mise run check`, `openspec validate --strict`, `mise run codegen-check`, `flutter build apk --release`, ручные проверки). Ожидаемые артефакты: tasks.md, results_scroll_keeper.dart, тест выдачи.

## F5 · Low — В Badge представимо состояние без значка и слова

- **Решение:** Устранить
- **Как устранить:** Исправить в этой ветке новой задачей в конце Phase 1 tasks.md с номером 1.<следующий свободный>. Требуемый результат: варианты метки Badge выражены закрытым (sealed) типом, поэтому состояние без значка и слова не представимо, а ветки `(null, null) => throw StateError(...)` и разбора пары полей в `build` нет. Именованные конструкторы `Badge.mark`, `Badge.archived`, `Badge.word` остаются const, с теми же параметрами; вид, цвета, размеры и узлы экранного диктора не меняются. test/design_system/relation_row_test.dart читает `badge.icon` и `badge.tone`: сохранить эти геттеры, если это не возвращает необязательное поле в модель вариантов, либо перевести проверку на видимый результат; решает сессия исполнения по меньшей цене, не ослабляя проверку. Компонент остаётся представлением без предметной логики. Новых тестов не добавлять: состояние исключает компилятор, а поведение закрывает test/design_system/badge_test.dart. Проверка: `flutter test test/design_system/badge_test.dart test/design_system/relation_row_test.dart` и `flutter analyze`. Завершающая задача: если в implementation-review-decisions.md, кроме этой находки, не осталось других, после своей задачи добавить последнюю задачу Phase 1 — повторить проверки задачи 1.8 (`grep` на `excludedIntentionId`, `mise run check`, `openspec validate --strict`, `mise run codegen-check`, `flutter build apk --release`, ручные проверки). Ожидаемые артефакты: tasks.md, lib/src/design_system/components/badge.dart и при необходимости relation_row_test.dart.
