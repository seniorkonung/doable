### F1 · Low — После подтверждённой отметки управление действует по прежней отметке до получения снимка

- **Evidence:** Координатор освобождает ключ намерения до публикации завершения (`lib/src/graph/application/graph_command_coordinator.dart:852-860`). Модель страницы при завершении снимает признак выполняющейся операции микрозадачей (`lib/src/intention/presentation/details/intention_details_view_model.dart:268-274`, `:516-527`), успех только очищает переход (`lib/src/intention/presentation/details/intention_details_view_model.dart:404-414`), а новые подробные данные приходят отдельным асинхронным чтением после перезапуска наблюдения (`lib/src/intention/presentation/details/intention_details_view_model.dart:308-311`). До этого чтения `details.favoriteMark` остаётся прежней, применимость перехода считается по ней (`lib/src/intention/presentation/details/intention_details_view_model.dart:482-485`), а значок, подсказка и действие управления берутся из неё же при доступности только по `isOperationRunning` и `edit` (`lib/src/intention/presentation/details/intention_details_page.dart:152-166`). Повтор команды адаптер возвращает успехом без изменения (`lib/src/graph/data/drift_personal_graph_repository_favorite_marks.dart:110-112`), а общая поверхность выбирает сообщение по виду команды (`lib/src/graph/presentation/graph_operation_presenter.dart:442-445`). Тест «отметка и её снятие применимы только при смене подтверждённого состояния» в `test/intention/presentation/details/intention_details_view_model_test.dart` фиксирует промежуточное состояние, но не доступность управления в нём.
