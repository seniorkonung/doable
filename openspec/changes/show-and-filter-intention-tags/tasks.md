# Задачи по фазам

Документ содержит пакеты задач [плана](plan.md) по фазам. Поведение определяют [спецификации намерений](specs/intention-management/spec.md), [дневных выборов](specs/daily-choice-management/spec.md) и [участников связей](specs/long-term-relation-management/spec.md); подход и архитектурные ограничения — [design](design.md) и [манифест ADR](adr.md).

Первая фаза охватывает общий контракт поиска и его выполнение. Вторая фаза охватывает согласование уже открытой выдачи с подтверждёнными изменениями тегов. Конкретный интерфейс и подключение предъявления тегов относятся к третьей фазе. При реализации учитывается доступный результат параллельного PR; эти пакеты не изменяют миграции удаления тегов у связей и не зависят от сохранения таких назначений.

Каждый инкремент включает проверки нового поведения с подтверждённым провалом до реализации и успехом после неё. После изменений Dart применяются правила репозитория для проверки запущенного приложения либо CLI. Пути ниже обозначают ожидаемые места изменений; новые тестовые файлы отмечены отдельно.
