## F3 · Low — Delta `intention-management` повторяет обязательства, у которых есть свой владелец, и держит сценарии пустой выдачи каталога в чужом требовании

- **Решение:** Устранить
- **Как устранить:** Вариант A (REMOVED + ADDED) через openspec-update-change; код, поведение, tasks.md и plan.md не меняются, правится только specs/intention-management/spec.md изменения. 1) В ADDED «Кнопка фильтра по тегам в поиске намерений» оставить: четыре контекста, показ условий кнопкой (без условий — значок, при условиях — выделение и число, каждое обязательное и исключённое условие — одно), доступное название с фильтром по тегам и числом условий, открытие панели тегов в режиме фильтра, отсутствие условий под полем. Повторы (одно условие на тег, немедленное применение, отличие пустой выдачи от пустого охвата, запрет менять теги, несохранение после закрытия) заменить ссылками на «Условия по тегам в панели тегов», «Согласованность параметров совместного поиска», «Пустая выдача поиска намерений», «Совместная фильтрация намерений по названию и тегам», «Самостоятельное состояние открытых страниц поиска намерений». Сценарий «Кнопка фильтра показывает число условий» оставить. Сценарий «Пустая выдача по условиям отличается от пустого охвата» не удалять, а перенести в «Пустую выдачу поиска намерений»: пусто только из-за тегов — сообщение, что под эти теги ничего не подходит, «Сбросить фильтры», без сообщения пустого охвата. 2) MODIFIED «Состояния получения данных» убрать; внести его в REMOVED с Reason (состав пустых сообщений перенесён в «Пустую выдачу», MODIFIED не может терять сценарии) и Migration; добавить ADDED «Состояния получения каталогов и подробных данных намерений» с тем же текстом и всеми сценариями, кроме «Пустой активный каталог», «Пустой архив», «Пустой охват всех намерений», «Фильтр без совпадений». 3) Эти четыре сценария перенести в «Пустую выдачу», согласовав THEN с её текстом (третья причина каталога для активного при непустом архиве, архивного, всех намерений; первая причина только по названию). 4) mise exec --no-deps -- openspec validate redesign-intention-catalog --strict.
