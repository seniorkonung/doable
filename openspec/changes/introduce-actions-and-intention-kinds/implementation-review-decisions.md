## F2 · Low — Связи в `RelationBatchAdded` никто не читает, а успех добавления разбирается дважды

- **Решение:** Устранить
- **Как устранить:** Устранить без изменения поведения. Убрать из `RelationBatchAdded` (`lib/src/long_term_relation/presentation/batch_picker/relation_batch_state.dart`) поле `relations`, сделав его маркером подтверждённого добавления без данных (обновить doc-комментарий), и разбирать исход успешного `AddLongTermRelations` (`LongTermRelationsAdded`) в одном месте в `relation_batch_view_model.dart`: `submit()` и `_finish` не должны дублировать разбор результата завершения команды. Неизменные ограничения: якорь пути (задача 2.26) получает связи из future, возвращаемого `submit()`, и получает их даже после ухода с поиска до исхода записи; поведение поиска участника для других якорей, правило `canPop`, закрытие поиска через `removeRoute` и надпись «Добавляем…» не меняются; поиск участника остаётся общим модулем (ADR-0049). Ожидаемые изменения: `relation_batch_state.dart`, `relation_batch_view_model.dart`, при необходимости `relation_batch_picker_page.dart`, перегенерированный `relation_batch_view_model.g.dart` (`mise run codegen-check` должен пройти). Существующие тесты задачи 2.26 и поиска участника должны проходить без ослабления. Новые задачи не добавлять; если процессу нужна отслеживаемая задача, добавить её только в конец Phase 2 следующим свободным номером 2.N.
