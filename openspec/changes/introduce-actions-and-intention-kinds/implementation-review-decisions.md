## F4 · Low — Каскадное удаление выразимо без подтверждения

- **Решение:** Устранить
- **Как устранить:** Устранить вариантом (а): каскадное удаление непредставимо без явного подтверждения человека. Добавить в конец фазы 4 tasks.md новую задачу 4.<следующий свободный номер>. Сделать функцию подтверждения обязательным параметром `delete` в IntentionDetailsViewModel (lib/src/intention/presentation/details/intention_details_view_model.dart) и RelationDetailsViewModel (lib/src/long_term_relation/presentation/details/relation_details_view_model.dart), а в `_startCascadeOperation` / `_startLifecycleChange` убрать путь, при котором удаление без подтверждения уходит с вариантом по умолчанию CascadeChoice.withSupporting; отказ подтверждения (null) по-прежнему отменяет операцию. Страницы уже передают подтверждение, поведение интерфейса не меняется. Тесты, вызывающие `delete()` без подтверждения (например intention_details_view_model_test.dart около строк 637, 706, 838 и аналогичные для связи), передают подтверждение явно. Если F9 уже реализована, строить выполнение через её фабрику из плана и выбора. Проверка: `mise exec --no-deps -- flutter test test/intention/presentation/details test/long_term_relation/presentation/details`. Ожидаемые артефакты: tasks.md, обе модели представления и их тесты.
