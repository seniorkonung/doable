## Findings

### F1 · Medium — Каждая порция вкладки «Действия» перебирает все строки пути намерения

- **Evidence:** `lib/src/graph/data/drift_personal_graph_repository_intention_actions.dart:90-111` выбирает порцию из `action_path_items p JOIN actions a` по `p.intention_id = ?` и сортирует по `a.date DESC, COALESCE(a.scheduled_hour, -1) DESC, a.creation_sequence DESC`. Курсор продолжения (строки 74-82) сравнивает те же столбцы `actions`. Единственный индекс строк пути по намерению — `action_path_items_intention_action (intention_id, action_id)` (`lib/src/data/local/schema/action_schema.drift:77`). Он не даёт ни порядка, ни поиска по курсору, поэтому каждая порция, включая продолжения, читает все строки пути намерения с поиском действия по ключу и сортирует их до `LIMIT`. Первая порция дополнительно делает второй полный проход для чисел ролей (строки 151-165). Чтение выполняется в `_sequencer.run` (строка 19), то есть в общей очереди с записями графа.
