## Findings

### F46 · Low — Критерий 2.4 делает единственное намерение пути простым текстом

- **Evidence:** `tasks.md:632`, задача 2.4: «Названия корня и промежуточных намерений — кнопки, последнее — простой текст». `specs/action-paths/spec.md:150`, «Сокращение пути и смена корня»: «Название последнего намерения, если оно не корневое, MUST быть простым текстом без действия: в пути из одного намерения оно корневое и остаётся кнопкой». README `PathBuilder` в `context/doable-design-system/components/` содержит ту же двусмысленность. Путь из одного намерения — первое состояние каждого пути: выбор в поиске начала пути по требованию «Поиск начала пути» начинает путь из одного намерения.
- **Impact:** Если компонент определяет простой текст по положению, после выбора первого корня на экране пути нельзя сменить корень нажатием на него. Тогда задаче 2.8 придётся переделывать компонент задачи 2.4, а тесты 2.4 закрепят неверное правило.
- **Required change:** Критерий задачи 2.4 и тест компонента называют исключение: в пути из одного намерения его название — кнопка корня, а простым текстом остаётся только последнее намерение пути из двух и более намерений.
