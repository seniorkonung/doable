## F12 · Low — Недоступный пункт меню принимает тон, который ни на что не влияет

- **Решение:** Устранить
- **Как устранить:** Устранить (рекомендация принята пользователем). Добавить в конец tasks.md новую задачу фазы 4 с номером 4.27, после задачи по F11. Задача по F10 тоже меняет options_menu.dart и его тест, поэтому эта идёт после неё. Исход: конструктор OptionsMenuItem.unavailable в lib/src/design_system/components/options_menu.dart больше не принимает параметр tone. Недоступный пункт всегда имеет обычный тон: выключенная строка OptionRow по README рисуется fill/grip независимо от тона. Вызов в lib/src/intention/presentation/details/intention_options.dart (выключенное «Удалить») и проверки test/design_system/options_menu_test.dart (около строк 122 и 152) перестают передавать tone недоступному пункту. Вид и поведение меню и строк не меняются, у доступных пунктов опасный тон сохраняется. Ожидаемые изменения: tasks.md (задача 4.27), options_menu.dart, intention_options.dart, options_menu_test.dart.

- **Решение:** Устранить
- **Как устранить:** Устранить (рекомендация принята пользователем). Добавить в конец tasks.md новую задачу фазы 4 с номером 4.28, последней из новых задач по этому ревью. Исход: из test/intention/presentation/details/intention_details_page_test.dart удалить проверку «показывает архивное состояние и отсутствие описания» (строки около 225-244).
