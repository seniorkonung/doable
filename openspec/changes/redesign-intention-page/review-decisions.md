## F9 · Low — Проверки 6.7 и 6.19 не закрепляют часть правил срока жизни группы и модели «Связей»

- **Решение:** Устранить
- **Как устранить:** Устранить через openspec-update-change правкой только незавершённых задач 6.7 и 6.19 в tasks.md, без новых задач и без изменения поведения продукта. 6.7: в проверки модели добавить, что после первого создания модели экземпляра новая модель того же экземпляра сохраняет выбранную группу, когда готовность в последнем снимке подробных данных изменилась, и что группа, выбранная после открытия по цели, не возвращается к группе цели при новой модели. 6.19: в проверки страницы добавить (1) смену готовности на «Обзоре» после показа «Связей» и возвращение на «Связи» с прежней группой; (2) открытие другой страницы над страницей намерения (подробности связи) при выбранной вкладке «Связи»: модель со строками сохраняется, после «назад» нет новых чтений первой порции и загруженные строки на месте. Явно заменить в 6.19 указание «с прежними ожиданиями» для сценария «вкладка и группа переживают переключения и страницу сверху, назад закрывает страницу» в test/intention/presentation/details/intention_details_tabs_test.dart: после «Связи» → «Обзор» → «Связи» ожидаются новые получения первых порций показанных частей вместо неизменного числа чтений relationGroupQueries; ожидание отсутствия чтений после возвращения со страницы сверху сохраняется. Ожидаемые изменения: tasks.md (6.7, 6.19); затем повторная проверка review.

## F10 · Low — 6.13 обосновывает отказ от `pretty` отсутствием потребителя, хотя README назначает его пустым группам «Связей»

- **Решение:** Устранить
- **Как устранить:** Вариант А: реализовать правило pretty из README EmptyState для пустых групп «Связей». Через openspec-update-change: 6.13 — у EmptyState появляется необязательный флаг pretty, выключенный по умолчанию (нынешние потребители не меняются). При включённом флаге, если текст занимает больше одной строки, а последняя строка состоит из одного слова, ширина текста подбирается наибольшей, не больше textWidth, при которой в последней строке не меньше двух слов и число строк не растёт; если такой ширины нет, применяется обычный перенос. Замер — по правилам Text (стиль, масштаб, локаль, направление), как в lib/src/design_system/text_metrics.dart. Убрать pretty из фразы 6.13 «Других параметров README … нет: у них нет потребителя» (для minHeight и level она остаётся). Компонентные проверки 6.13 подтверждают перенос слова в последнюю строку при включённом флаге, отсутствие изменений при выключенном и случай без подходящей ширины. 6.16 включает pretty для всех пустых групп «Связей», включая архивированное намерение, и проверяет, что флаг передан. В решении 11 design.md строку EmptyState дополнить правилом pretty. Новых задач не добавлять; ожидаемые изменения: tasks.md (6.13, 6.16), design.md (решение 11); затем повторная проверка review.
