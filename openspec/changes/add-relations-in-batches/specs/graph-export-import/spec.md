## MODIFIED Requirements

### Requirement: Состав файла экспорта
Файл экспорта MUST содержать весь граф намерений: активные и архивированные намерения, теги и их назначения намерениям, активные и архивированные долговременные связи и все дневные выборы вместе с их путями выбора. Для каждой сущности файл MUST сохранять её идентификатор и все данные, которые определяют соответствующие capability: название, описание, готовность к действию, архивное состояние и показания времени создания и последнего изменения намерения; название, цвет и место в ручном порядке тега; тип, участников, приоритет, описание, архивное состояние и показания времени создания и последнего изменения долговременной связи; участников, дату, запланированное время, приоритет, выполнение, описание и путь дневного выбора. Файл MUST сохранять и все видимые пользователю порядки: ручной порядок тегов и последовательность создания долговременных связей и дневных выборов.

Статистика, состояния дней и другие производные данные MUST NOT входить в файл: после импорта они вычисляются из импортированного графа. Настройки установки, в том числе режим быстрого создания, и резервные копии MUST NOT входить в файл.

Файл MUST отражать одно подтверждённое состояние графа: изменение, подтверждённое во время экспорта, MUST попадать в файл целиком либо не попадать вовсе.

#### Scenario: Импорт экспорта воспроизводит граф
- **GIVEN** граф содержит архивированное намерение, две связи «нужно» одного намерения с приоритетом P2, созданные одна за другой, дневной выбор, путь которого проходит через ныне архивированную связь, синий тег, назначенный намерениям А и Б и вручную переставленный перед созданным раньше него тегом без цвета
- **WHEN** пользователь экспортирует граф и импортирует файл в другой установке
- **THEN** там доступны те же сущности с теми же идентификаторами и данными, включая синий цвет одного тега, отсутствие цвета другого, их ручной порядок и оба назначения синего тега, связи с P2 идут в прежнем порядке, а путь дневного выбора сохранён

#### Scenario: Настройки установки не переносятся
- **GIVEN** в исходной установке выбран режим быстрого создания «Новый дневной выбор», а в целевой — «Новое намерение»
- **WHEN** файл экспорта исходной установки импортируется в целевую
- **THEN** в целевой установке остаётся режим «Новое намерение»

#### Scenario: Изменение во время экспорта
- **GIVEN** выполняется экспорт большого графа
- **WHEN** пользователь архивирует намерение вместе с его связями
- **THEN** файл содержит это намерение и все его связи либо в состоянии до архивирования, либо в состоянии после него
