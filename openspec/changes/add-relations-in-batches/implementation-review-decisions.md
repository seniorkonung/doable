## F1 · Medium — Сгенерированный файл модели подробного просмотра устарел

- **Решение:** Устранить
- **Как устранить:** Решение пользователя: закрыть F1 в следующей сессии разбора этой находки, без новой задачи. ЯВНОЕ ИСКЛЮЧЕНИЕ, разрешённое пользователем: эта сессия запускает `mise run codegen-check` и при необходимости `mise run codegen`, хотя общие правила таких сессий запрещают тесты, сборки и проверки проекта и меняют только планирующие артефакты; исключение действует только на эти две команды, только для F1 и только в этой сессии, другие тесты и проверки не запускать. Требуемый исход: `mise run codegen-check` завершается с кодом 0 на ветке `change/add-relations-in-batches`, а `lib/src/long_term_relation/presentation/details/relation_details_view_model.g.dart` соответствует исходнику модели. Контекст: коммит 2cc712c2 уже заменил хеш в этом файле на `11dbe095db4104e080681cc7168763a8d65eb2fd`, исходник модели после 718e891a не менялся. Шаги: запустить `mise run codegen-check` на чистом рабочем дереве. Если код 0, снять F1 из `implementation-review.md` как исправленную коммитом 2cc712c2. Если код не 0, в этой же сессии выполнить `mise run codegen`, закоммитить только изменённые сгенерированные файлы, снова запустить `mise run codegen-check` и при коде 0 снять F1 как исправленную этим коммитом; если код снова не 0, F1 не снимать и вернуть её на решение с выводом проверки. Не добавлять задачи в `tasks.md`, не менять `plan.md`, другие фазы и артефакты планирования, не встраивать `codegen-check` в `mise run check`: скрипт требует чистую рабочую копию. Поведение приложения не меняется. Принятие риска не применяется.
