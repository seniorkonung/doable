## F8 · Low — Изменённое требование о долговечности обещает обновление, которого нет

- **Решение:** Нужно новое решение
- **Препятствие:** Решение F8 невыполнимо как записано: MODIFIED не может удалить сценарий, и validate --strict с archive отвергают RENAMED+MODIFIED без «Обновление установки с намерениями». Нужно выбрать: REMOVED старого + ADDED нового требования с Reason/Migration, как уже сделано в этой дельте (требование уйдёт в конец спецификации, переименования не будет), либо другой путь. Правки откачены, коммитов нет.
