### F2 · High — Сценарий навигации по тегу зависит от неопределённого порядка строк SQLite

- **Evidence:** `test/app/tag_navigation_graph_lifecycle_scenarios.dart:141-149` на 70365bf7c9b84a155d03006fcd8497beec8d174d — файл вне диапазона, его запускает `test/app/tag_navigation_app_flow_test.dart`. Проверка сравнивает результат `SELECT * FROM tag_assignments WHERE tag_id = ?` без `ORDER BY` со строками `before['tag_assignments']`, которые идут в порядке `creation_sequence`. На 70365bf7c9b84a155d03006fcd8497beec8d174d строки приходят в порядке намерений: `creation_sequence` 2, 5, 11, 6, 12 вместо 2, 5, 6, 11, 12, и проверка «открытая навигация обновляет поля и порядок назначений» падает в строке 141. На 37eb68ac52961839b545eb0f3b8b873916218510 та же проверка проходит. Изменение схемы в 9766396248cb3e81f3c0bed6dce5bab3e1aa852d сменило план запроса, а порядок без `ORDER BY` SQLite не гарантирует.
- **Evidence revisions:** ["70365bf7c9b84a155d03006fcd8497beec8d174d"]
- **Impact:** `mise run check` на голове фазы не проходит. Проверка ломается от любого изменения схемы или плана запроса, не связанного с её поведением.
- **Required outcome:** Сравнение назначений не зависит от неопределённого порядка строк, и проверка проходит на исправленной голове.
- **Earliest source of truth:** implementation/tests
- **Affected artifacts:** ["test/app/tag_navigation_graph_lifecycle_scenarios.dart", "openspec/changes/add-tags-panel/tasks.md#1.7"]

### F3 · Low — Комментарии изменённых проверок называют порядок создания тегов

- **Evidence:** На 70365bf7c9b84a155d03006fcd8497beec8d174d комментарии в изменённых диапазоном файлах описывают порядок, который больше не определяет видимый порядок тегов. - **Evidence revisions:** ["70365bf7c9b84a155d03006fcd8497beec8d174d"]
- **Impact:** Комментарий скрывает, какой контракт защищает ожидание. Будущее изменение порядка, например перестановка фазы 3, может «исправить» проверку под неверный контракт.
- **Required outcome:** Комментарии этих проверок описывают ручной порядок тегов или явно указывают, что фикстура совмещает его с порядком создания.

### F4 · Low — Проверка изменения только цвета строит недостижимую смену места

- **Evidence:** В `test/intention/application/intention_contract_test.dart:358-394` на 70365bf7c9b84a155d03006fcd8497beec8d174d проверка называется «изменение только цвета тега заменяет его состояние в сводке», но передаёт в `withUpdatedTag` тег с местом `tagPositionAt(1009)` вместо исходного `tagPositionAt(1008)`. В фазе 1 `UpdateTag` место не меняет (design, решение 2), а соседние проверки согласования сохраняют место, например `position: health.position`.
- **Evidence revisions:** ["70365bf7c9b84a155d03006fcd8497beec8d174d"]
- **Impact:** Проверка закрепляет поведение для состояния, которое изменение тега не создаёт, и противоречит своему названию. Когда фаза 3 добавит пересортировку сводок по месту, ожидание порядка `[firstId, secondId]` будет смешивать два разных события.
- **Required outcome:** Входные данные проверки соответствуют её сценарию: изменение только цвета сохраняет место тега.
- **Earliest source of truth:** implementation/tests
- **Affected artifacts:** ["test/intention/application/intention_contract_test.dart"]
