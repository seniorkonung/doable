# ADR-0027: Перечитывать статистику только при показе

- Status: proposed
- Originating change: add-contribution-statistics
- Date: 2026-10-12

## Контекст

[ADR-0024](0024-derive-calendar-day-states-from-saved-daily-choices.md) согласует отметки дней повторным чтением после каждой новой подтверждённой ревизии: их чтение — дешёвый ограниченный агрегат. Чтение статистики вклада заметно дороже, особенно в виде «Через связи» по [ADR-0026](0026-compute-contribution-through-relations-off-queue.md).

Главная — стартовая корневая страница. По [ADR-0014](0014-host-primary-navigation-in-root-page-shell.md) и [ADR-0020](0020-host-persistent-navigation-in-ordinary-page-scaffolds.md) она живёт до конца процесса, а страницы намерений с разделом статистики остаются в истории под другими страницами. Если перечитывать статистику после каждой ревизии, любая правка в любом разделе — например, при построении графа — ставила бы скрытое чтение статистики в общую очередь [ADR-0009](0009-unify-personal-graph-module-and-revision.md). Спецификация при этом требует отражать подтверждённые изменения без ручного обновления и до замены показывать прежние числа с признаком обновления.

## Решение

Модели статистики слушают завершения координатора команд, но более новая ревизия только помечает их данные устаревшими и не запускает чтение. Страница сообщает модели свою видимость. Главная видна, когда выбран её пункт и поверх неё ничего не открыто. Раздел статистики намерения виден, когда его страница верхняя в истории.

Видимая модель с устаревшими данными перечитывает уже загруженную часть — сводку, карточки и загруженные порции — и заменяет её одной операцией. До замены остаются прежние числа с признаком обновления, а при отказе — с признаком неудачного обновления. Смена местной даты обрабатывается так же, потому что от неё зависит деление невыполненного. Смена условий начинает новое поколение чтений; ответы прежних поколений и старых ревизий отбрасываются по правилам ADR-0009.

Решение относится к статистике. Отметки дней по-прежнему согласуются по ADR-0024.

## Последствия

- Пока статистика скрыта, она ничего не читает, и правки в других разделах не добавляют её чтений в общую очередь.
- При возврате к статистике после изменений сначала видны прежние числа с признаком обновления. Это требуемое спецификацией поведение.
- Страница обязана сообщать видимость через одну точку. Проверки доказывают отсутствие чтений, пока статистика скрыта, и одно обновление при показе.
- Будущее производное представление выбирает между этим правилом и ADR-0024 по стоимости своего чтения.
