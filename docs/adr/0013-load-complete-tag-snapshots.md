# ADR-0013: Читать списки тегов полными согласованными снимками

- Status: proposed
- Originating change: stabilize-tag-selection
- Date: 2026-09-28

## Контекст

Тег — переиспользуемая метка личного графа; число самих тегов ожидается небольшим. Ограниченные порции полезны для намерений, связей и выдачи сущностей по тегу, но усложняют небольшой каталог. Решение дополняет общую границу и ревизию графа из ADR-0009.

## Решение

Контракт личного графа получает каталог тегов и назначения одного получателя полными неизменяемыми снимками на одной транзакции и ревизии. Каталог выбора содержит признаки назначения выбранному получателю. Чтение этих списков не имеет курсоров, размеров порций и искусственного предела числа тегов. Общий последовательный исполнитель, проверка данных, устойчивый порядок и типизированные отказы сохраняются. Выдача помеченных сущностей остаётся ограниченной.

## Последствия

Выбор строки не требует перечитывания каталога; исчезает согласование его продолжений. Стоимость списка пропорциональна числу тегов, что принимается для небольшого каталога. Запрос не получает весь граф или все помеченные сущности. Изменение ожидаемого масштаба тегов потребует отдельного пересмотра.
