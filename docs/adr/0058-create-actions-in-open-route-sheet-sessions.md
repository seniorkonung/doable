# ADR-0058: Создавать действия в листе-маршруте, который остаётся открытым

- Status: proposed
- Date: 2026-11-06
- Originating change: introduce-actions-and-intention-kinds
- Supersedes: [ADR-0022](0022-complete-creation-flows-within-owned-route-boundaries.md) в части завершения потока для действия: создание действия не закрывает лист и не открывает созданное. Для намерения правило завершения остаётся в силе; [ADR-0020](0020-host-persistent-navigation-in-ordinary-page-scaffolds.md) в части черновиков листа нового действия: сброс истории пунктом нижней панели спрашивает о введённом тексте, а не сбрасывает без подтверждения потери несохранённых данных, и обычные страницы доступны над листом вопреки предпосылке об их недоступности из модальной сессии создания. Для остальных страниц и модальных сессий создания правила ADR-0020 остаются в силе.

## Контекст

Действия создаются подряд, как задачи в списке дел: после создания лист очищает название и описание и остаётся открытым для следующего действия. Лист можно открыть со страницы намерения, открытой из поиска внутри другого потока создания действия, и тогда поверх первого черновика появляется второй. Сброс истории пунктом нижней панели не должен молча терять введённый текст. Лист без маршрута не виден стеку маршрутизатора, и перехват сброса потребовал бы отдельного реестра черновиков.

## Решение

Лист нового действия — прозрачный маршрут над корневым навигатором с собственной сессией черновика, как модальные сессии создания [ADR-0018](0018-manage-modal-creation-sessions-in-root-stack.md). Каждое открытие создаёт свою сессию; сессия переходит «ввод → создание → ввод с очищенными названием и описанием» и не имеет завершающего состояния, поздний результат только согласует данные и сообщение. Закрытие при непустых названии или описании и без идущего создания спрашивает «Отменить новое действие?».

Сброс истории пунктом нижней панели перехватывается в одном месте навигации: перед сбросом она просматривает стек корневого маршрутизатора и один раз спрашивает, если хоть в одной сессии листа введён текст.

Отклонённые варианты: лист без маршрута с глобальным реестром черновиков — второй источник истины о стеке; закрывать лист после создания по ADR-0022 — противоречит созданию действий подряд.

## Последствия

- Граница потока, сохранение исходной истории и независимость принятой команды из ADR-0022 остаются в силе для листа действия.
- Любой будущий черновик, который нельзя терять при сбросе истории, подключается к той же проверке стека.
