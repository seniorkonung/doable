# ADR-0043: Получать количество связей только для страницы намерения

- Status: proposed
- Originating change: redesign-intention-pickers
- Date: 2026-10-23
- Supersedes: [ADR-0011](0011-derive-relation-counts-from-graph-snapshots.md) в части количеств для каталога и миниатюр, получаемых пакетно по идентификаторам порции; [ADR-0009](0009-unify-personal-graph-module-and-revision.md) в части замены чисел в загруженных строках каталога при изменении только счётчиков.

## Контекст

По [ADR-0011](0011-derive-relation-counts-from-graph-snapshots.md) количество непосредственных связей входит в краткие данные намерения. Его получают агрегатом по своей порции:

- строки каталога и поисков намерений;
- соседи в разделе связей страницы намерения;
- участник в форме и подробностях связи.

По [ADR-0009](0009-unify-personal-graph-module-and-revision.md) модель каталога заменяет числа в загруженных строках при каждом изменении только счётчиков.

Владелец продукта решил показывать количество связей только на странице самого намерения — сводкой групп; строки списков в дизайн-системе его не несут. Если краткие данные продолжат его нести, система будет делать лишнюю работу ради числа, которое никто не видит:

- каждое чтение порции, снимок команды и группа связей будут вычислять агрегаты и проверять соседство;
- модели будут перечитывать группы, когда меняются числа соседей.

## Решение

**Где число есть.** Количество связей намерения — данные только его страницы. Краткие данные намерения в каталоге и поисках и краткие данные участника связи количества не содержат и не получают.

**Где вычисляется агрегат.** Агрегаты [ADR-0011](0011-derive-relation-counts-from-graph-snapshots.md) вычисляются только там, где число показывают или где по нему согласуется страница намерения:

- сводка владельца на первой порции группы и в наблюдении намерения;
- численная сводка связей намерения;
- абсолютные количества затронутых намерений в пакетах подтверждённых команд.

**Что сохраняется.** Остальные решения ADR-0011 остаются в силе:

- источник истины — сохранённые связи;
- агрегаты вычисляются без материализации списков;
- сводка — восемь проверенных количеств;
- повреждение — типизированный отказ;
- счётчики — прикладные проекции.

Остаются в силе и решения ADR-0009 о пакетах и согласовании групп.

**Проверка целостности.** Целостность соседства проверяется вместе с агрегатом, поэтому охватывает только намерения, чьи количества получены. Чтения каталога и участников соседство не проверяют: связей этих намерений они не показывают.

## Последствия

- **Без агрегатов ради кратких данных** работают: порция каталога, снимки команд намерений и назначений тегов, группы связей, подробности связи, выбранные связи и продолжения пути.
- **Модели проще.** Модель каталога не принимает числа из пакетов, а модель соседства не перечитывает группу, когда меняются числа соседа.
- **Пакеты команд не меняются.** Они по-прежнему несут абсолютные количества затронутых намерений: на них опирается согласование открытых страниц.
- **Повреждение соседства находится позже:** при открытии страницы намерения, а не при показе его строки в каталоге или в роли участника.
- **Новое решение для новых показов.** Если количество связей понадобится представлению вне страницы намерения, потребуется отдельное решение о его получении и согласовании.
