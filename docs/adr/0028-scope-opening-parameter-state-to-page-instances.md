# ADR-0028: Привязывать состояние, заданное параметрами открытия страницы, к её экземпляру

- Status: proposed
- Originating change: add-contribution-statistics
- Date: 2026-10-12

## Контекст

Состояние экрана дня — выбранная дата, фильтр выполнения, загруженные записи — сейчас одно на приложение, а модель отметок дней выбирается по начальной дате. [ADR-0017](0017-isolate-inline-calendar-behind-app-component.md) и [ADR-0025](0025-load-calendar-day-marks-in-separate-viewport-model.md) распределяют владение между моделью экрана дня, страницей и моделью отметок, неявно предполагая один экран дня.

Изменение `add-contribution-statistics` открывает экран дня на заданную дату обычной страницей в истории, а корневой экран дня при этом сохраняет своё состояние. Страница намерения открывается с целью статистики — видом и периодом — и может несколько раз встретиться в истории с разными целями. Модели страницы намерения выбираются по `IntentionId`: для данных самой сущности это верно, но параметры открытия данными сущности не являются.

## Решение

Состояние представления, заданное параметрами открытия страницы, принадлежит экземпляру страницы. Модели такого состояния — семейства по ключу экземпляра, который создаёт и удерживает сама страница. Это выбранная дата, фильтр выполнения, просматриваемый период, представление календаря и загруженные записи экрана дня, а также режим, периоды, вид и загруженные порции раздела статистики. У корневого экрана дня один ключ на процесс.

Данные самой сущности — подробности намерения и его группы связей — по-прежнему могут делиться между экземплярами по её идентичности. Границы владения ADR-0017 и ADR-0025 действуют внутри каждого экземпляра экрана дня: модель отметок живёт вместе со своим экземпляром.

## Последствия

- Открытие страницы с параметрами никогда не меняет другую открытую страницу и корневую страницу.
- Каждый экземпляр читает данные сам. Две страницы одного намерения считают статистику независимо.
- Модели живут и освобождаются вместе со своими страницами. Проверки доказывают независимость двух экземпляров и сохранность состояния корневого экрана дня.
- Будущие страницы, открываемые несколько раз с разными параметрами, в том числе вкладки страницы намерения, следуют этому правилу; цель статистики остаётся параметром открытия.
