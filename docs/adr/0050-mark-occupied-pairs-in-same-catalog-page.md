# ADR-0050: Отмечать занятые пары поиска участника в той же порции каталога

- Status: proposed
- Date: 2026-10-30
- Originating change: mark-occupied-pairs-in-relation-participant-picker

## Контекст

Поиск участника долговременной связи читает ограниченные порции каталога намерений по [ADR-0009](0009-unify-personal-graph-module-and-revision.md) и исключает участника другой роли по идентификатору. Направленную пару может занимать только одна связь любого типа и архивного состояния. Сейчас конфликт обнаруживается только при сохранении формы. Изменение `mark-occupied-pairs-in-relation-participant-picker` требует отмечать строки, выбор которых дал бы занятую пару, и отличать активную занимающую связь от архивной.

До сих пор чтения каталога и поисков не касались связей. [ADR-0043](0043-read-relation-counts-only-for-intention-page.md) оставил количество связей только странице намерения, а целостность соседства проверяется только вместе с агрегатом. Отметка — не количество: это одна связь одной пары на строку. Связи одного намерения за годы копятся без ограничения, в том числе в архиве.

## Решение

- **Проба пары в запросе.** Запрос каталога поиска участника несёт одно значение — пробу пары:
  - участника другой роли;
  - выбираемую роль;
  - изменяемую связь, которая пару не занимает.

  Из пробы выводятся и исключение участника по идентификатору, и проверка пары; отдельного поля исключения нет. Запрос без пробы ничего не исключает и не отмечает.
- **Занятость в той же порции.**
  - Хранилище находит занимающую связь каждой строки по уникальному индексу пары в том же транзакционном снимке и на той же ревизии, что и строки порции.
  - Порция несёт идентификатор и архивное состояние занимающих связей своих строк тогда и только тогда, когда запрос несёт пробу.
  - Принадлежность выдаче, порядок и точные числа от занятости не зависят.
- **Согласование фактами связей.** Модель каталога обновляет занятость загруженных строк по сведениям об изменённых связях из пакетов подтверждённых команд ADR-0009: прежнее состояние связи снимает её отметку, новое ставит.
  - Новое намерение входит в выдачу свободным.
  - Занятость строки, которая вошла в выдачу по изменению намерения, неизвестна. Для неё модель строит новую основу с первой порции.
- **ADR-0043 остаётся в силе.** Каталог и поиски по-прежнему не получают количеств связей и не проверяют целостность соседства.

**Отвергнуто:**
- **Один раз прочитать все связи участника другой роли.** Объём такого чтения ограничен только графом, а это противоречит ограниченным порциям ADR-0009.
- **Отдельное чтение занятости по идентификаторам порции.** Оно получает другую ревизию и требует собственного согласования.
- **Поле занятости в краткой сводке намерения.** Сводку делят каталог, поиски дневного выбора и снимки команд, а они о пробе не знают.

## Последствия

- Отметка согласована со своей строкой: старая порция не возвращает снятую отметку, а изменение связи не требует перечитывать выдачу.
- Порция дорожает на один поиск по индексу на строку и остаётся ограниченной своим размером.
- Модель каталога зависит от сведений о связях в пакетах. Изменение их формы должно сохранять прежних и новых участников и архивное состояние связи.
- Строка, вошедшая в выдачу по изменению намерения, сбрасывает загруженную часть поиска участника. Это редкий путь через страницы, открытые из поиска.
- Если другому назначению поиска понадобится сведение о строке из соседних сущностей, оно следует тому же образцу: значение в запросе, вычисление в снимке порции, согласование фактами пакетов.
- Тестовые репозитории соблюдают контракт пробы.
