# ADR-0060: Засчитывать действие через связи от существующих намерений его пути

- Status: proposed
- Date: 2026-11-06
- Originating change: introduce-actions-and-intention-kinds
- Supersedes: [ADR-0026](0026-compute-contribution-through-relations-off-queue.md) в части опорных намерений. Снимок активных связей, расчёт в фоновом изоляте, кэш по ревизии и сброс снимка изменениями связей остаются в силе.

## Контекст

ADR-0026 засчитывала дневной выбор намерениям, от которых по активным связям достижимо опорное намерение: выбранное действие или исходное намерение архивированного шага пути. Дневного выбора больше нет. Путь действия — последовательность намерений без ссылок на связи, удалённые намерения пути сохраняются только надгробиями ([ADR-0055](0055-store-action-path-as-intention-sequence-with-shared-tombstones.md)) и из статистики исчезают.

## Решение

Опорные намерения действия — все существующие намерения его сохранённого пути, включая архивные; удалённые опорными не являются. Вид «Через связи» засчитывает действие каждому опорному намерению и каждому намерению, от которого по активным связям достижимо хотя бы одно опорное. Действия периода по-прежнему сворачиваются в группы с одинаковым опорным набором. Внутри непрерывного участка активных звеньев опорное намерение, из которого достижимо следующее опорное, можно опустить без изменения результата.

Смена вида на достижимость не влияет и снимок связей не сбрасывает; каскады сбрасывают его через изменения затронутых связей.

## Последствия

- Опорных групп может стать больше, чем у дневных выборов; бюджет статистики подтверждается бенчмарком.
- Роли корневого, промежуточного и конечного намерения считаются запросами по позициям пути и снимка связей не требуют.
