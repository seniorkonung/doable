# ADR-0037: Экспортировать открытый файл через системные диалоги без разрешений

- Status: proposed
- Originating change: add-graph-export-import
- Date: 2026-10-17

## Контекст

Граф содержит личные тексты. [ADR-0004](0004-keep-personal-graph-device-local.md) хранит его во внутреннем хранилище, исключает из системного копирования и переноса, ограничивает набор разрешений точным списком и требует пересмотреть модель угроз до появления экспорта. Хост приложения — `FlutterActivity`, движок которой переносится между Activity при смене дисплея ([ADR-0031](0031-restrict-phones-to-portrait-full-screen.md)). Готовых плагинов работы с файлами в приложении нет.

Запись дополняет ADR-0004 и не меняет её решений о размещении данных и наборе разрешений.

## Решение

Файл экспорта не шифруется. Он появляется только по явному действию человека, а перед сохранением человек видит предупреждение, что файл не защищён. Само приложение не создаёт копий графа вне своего каталога: резервные копии, снимки и временные файлы лежат в каталоге приложения, уже исключённом из системного копирования и переноса.

Файлы выбираются системными диалогами Storage Access Framework (`ACTION_CREATE_DOCUMENT`, `ACTION_OPEN_DOCUMENT`) через встроенный Kotlin-плагин движка — без разрешений, без `FileProvider` и без изменений манифеста. Данные копируются потоками `ContentResolver` между документом и временным файлом приложения. Для импорта через канал передаётся только ограниченное начало документа: модуль формата Dart проверяет gzip и заголовок Doable до создания временной копии. После успешной проверки плагин копирует сохранённое начало и остаток того же открытого потока напрямую в файл; весь документ через канал не передаётся. Правила формата в Kotlin не дублируются. Запрос, прерванный отсоединением Activity, завершается как отмена. Временное право на выбранный документ снимается вместе с Activity, получившей ответ диалога, а движок переносится между Activity. Поэтому плагин закрепляет это право, пока та Activity жива, и отпускает его после операции. Право, оставшееся после завершения процесса, отпускается при следующем запуске: постоянных прав на документы приложение не хранит. Диагностика не содержит имён, адресов и содержимого файлов.

## Последствия

- Любой, у кого есть файл, может прочитать граф. За хранение файла отвечает человек.
- Проверка набора разрешений остаётся прежней. Его изменение по-прежнему требует решения по ADR-0004.
- Шифрование файла экспорта потребует отдельного решения о ключах и восстановлении доступа.
- Постоянный доступ к документу или папке, если он понадобится будущей функции, потребует пересмотра записи: при запуске приложение отпускает все закреплённые права.
- Чужой заголовок и более новая версия отклоняются без полного чтения и временной копии; допустимый заголовок не отменяет последующей проверки всего файла. Плагин владеет потоком и правом до завершения проверки и копирования либо отказа и отмены. Предварительной загрузкой внутри облачного поставщика приложение не управляет.
- Плагин — нативный код, его поведение проверяется вручную на устройстве и через Dart-сторону канала.

## Отклонённые альтернативы

- Шифрование файла паролем: забытый пароль безвозвратно лишает доступа к данным; этот же риск ADR-0004 называет против шифрования базы.
- Сторонние плагины выбора файлов: неизвестные записи манифеста и API, которые отдают файл целиком в памяти.
- `package:jni`: нет интеграции с результатами Activity.
- Передача всего файла через канал порциями: сложнее и медленнее копирования через временный файл. Передача ограниченного начала позволяет проверить заголовок до копирования без второго кодека в Kotlin.
- Держать документ открытым от ответа диалога до копирования: документ открыт всё время сборки файла, а плагин отвечает за открытые дескрипторы на каждом пути.
