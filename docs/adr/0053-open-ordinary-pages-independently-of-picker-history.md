# ADR-0053: Открывать обычные страницы независимо от поиска в истории

- Status: proposed
- Date: 2026-11-03
- Originating change: open-full-intention-pages-from-pickers
- Supersedes: [ADR-0052](0052-add-relations-as-one-batch-from-group-picker.md) в части запрета панели навигации и нового создания над поиском участника связи и предположения, что новые связи не возникают, пока поиск открыт.

## Контекст

ADR-0052 скрывает навигацию, добавление связей и создание действия на всех страницах над поиском участников, чтобы сброс истории не терял отметки. Страница намерения, открытая стрелкой из поиска, получает контекст его отметок и показывает кнопку выбора вместо обычной навигации. Такая защита мешает продолжить декомпозицию найденного намерения и делает возможности страницы зависимыми от незавершённой задачи ниже в истории.

Изменение `open-full-intention-pages-from-pickers` возвращает полноценную страницу намерения из любого поиска. Оно частично пересматривает ADR-0052, сохраняя его атомарную команду добавления, владение отметками экземпляром поиска и завершение добавления возвратом к группе. Исходная запись принадлежит архивному изменению и сохраняется вместе со своим статусом `proposed`.

## Решение

Каркас обычной страницы определяется её назначением по [ADR-0020](0020-host-persistent-navigation-in-ordinary-page-scaffolds.md). Наличие поиска ниже в истории не меняет её навигацию и доступность предметных действий. Открытая страница намерения не принимает модель отметок поиска; выбор остаётся ответственностью самого поиска.

Вложенное создание использует общий корневой стек и существующие границы собственного потока по [ADR-0022](0022-complete-creation-flows-within-owned-route-boundaries.md), а добавление связей — границу экземпляра поиска по ADR-0052. Параметры и отметки каждого поиска принадлежат его экземпляру по [ADR-0028](0028-scope-opening-parameter-state-to-page-instances.md). Общая история не объединяет их в одну сессию и не делает вложенные записи частью первоначальной несохранённой пачки.

Предположение об отсутствии новых связей при открытом поиске снимается. Модель отметок согласует весь отмеченный набор с подтверждёнными фактами графа по [ADR-0009](0009-unify-personal-graph-module-and-revision.md), а занятость строк продолжает следовать [ADR-0050](0050-mark-occupied-pairs-in-same-catalog-page.md). Согласование относится к владельцу отметок, включая скрытые фильтром намерения, и не требует передачи состояния поиска открытым страницам.

Сохранение особого каркаса или кнопки отметки у обычной страницы оставило бы зависимость от чужой задачи. Отдельный навигатор для вложенного создания повторил бы уже существующие границы общего стека. Эти варианты отклонены.

## Последствия

- Открытие намерения из поиска и дальнейшие переходы по графу используют обычные страницы; специальный контекст отметок больше не распространяется по маршрутам.
- Вложенное создание может занять пару первоначальной отметки. Её снимает модель соответствующего поиска по подтверждённому изменению, сохраняя остальные отметки и их порядок.
- Обычный возврат сохраняет первоначальный поиск. Выбор пункта навигации применяет существующий сброс истории без подтверждения потери несохранённых отметок; принятые и подтверждённые операции сохраняют собственный жизненный цикл.
- Последующие изменения поиска и страницы намерения должны сохранять эту границу ответственности. Правила допустимости связей и их проверка при сохранении остаются у модуля графа.
