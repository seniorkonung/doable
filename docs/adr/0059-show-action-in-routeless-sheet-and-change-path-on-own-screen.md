# ADR-0059: Показывать действие в листе без маршрута и менять его путь на отдельном экране

- Status: proposed
- Date: 2026-11-06
- Originating change: introduce-actions-and-intention-kinds
- Supersedes: [ADR-0054](0054-show-and-change-daily-choice-in-one-routeless-sheet.md) полностью, потому что дневной выбор заменён действием; [ADR-0022](0022-complete-creation-flows-within-owned-route-boundaries.md) в части возврата замены пути вызывающей странице.

## Контекст

ADR-0054 сделала подробный просмотр дневного выбора листом без маршрута и единственным местом его изменения, а путь выбора не менялся. Действие заменяет дневной выбор, и его путь меняется: «Изменить путь» открывает экран пути, где человек перестраивает цепочку и может по пути добавлять связи и намерения. По ADR-0022 такая замена возвращала бы результат вызывающей странице, но отказ записи тогда появился бы в панели, куда человек ещё не вернулся.

## Решение

Панель действия сохраняет правила ADR-0054 для действия: лист без маршрута, сразу записываемые дата, время, приоритет и выполнение, название и описание в изменении под полосой, страницы поверх листа и снятие листа сбросом истории.

Путь существующего действия меняется на экране пути — странице-задаче без нижней панели над листом. Экран сам выполняет замену пути, закрывается при успехе и показывает отказ на себе; после возврата панель показывает вкладку «Путь» с новым путём. Для нового действия тот же экран возвращает путь в лист, ничего не записывая.

Отклонённые варианты: выполнять замену в панели после возврата — отказ появляется вне экрана, где его вызвали; менять путь внутри панели — экран пути требует полной высоты, кандидатов и добавления связей.

## Последствия

- Лист остаётся местом изменения всех полей действия, кроме пути.
- Создание действия описывает [ADR-0058](0058-create-actions-in-open-route-sheet-sessions.md).
