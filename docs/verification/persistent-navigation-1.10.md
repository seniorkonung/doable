# Проверка постоянной панели — задача 1.10

Изменение: `add-quick-creation-and-persistent-navigation`. Дата: 2026-10-07.

Поведение панели по задаче 1.10 подтверждено автоматическими проверками, наблюдениями на Android и ручной проверкой пользователя. Обнаруженная ошибка раскладки `PageView` в закреплённом Flutter 3.47.1 сохранена ниже как известное ограничение SDK; она не исправлена, отсутствие любых ошибок приложения не заявляется.

## Автоматические проверки

- `app_navigation_accessibility_test.dart` проверяет три корневые страницы и все пять видов обычных страниц с каждым выбранным пунктом при масштабе текста 2.5. Для системных локалей `ru`, `en` и `de-DE` проверяются названия, английский fallback, роль вкладки и кнопки, положение среди трёх пунктов, единственный выбранный пункт, подсказки, отсутствие видимых подписей, целые значки и доступные заголовки. Действие экранного диктора возвращает к сохранённому корню.
- `app_navigation_transition_test.dart` измеряет 30 промежуточных кадров каждого перехода через настоящий `AppRouter` на экране 360 × 780 с нижним безопасным отступом 24. Для Android и iOS подтверждены единственная панель, неизменная геометрия и выбранный пункт, отсутствие исключений `Hero`, скрытие страницей-задачей и восстановление при возврате. Для iOS отдельно воспроизведены отмена и завершение краевого жеста «назад».
- Скрытая обычная страница исключена из обхода фокуса и семантики. Используемый сообщениями `PresentationFrameEvidence` не подтверждает сообщение скрытой страницы; после возврата подтверждает его ровно один раз.
- Примеры Widgetbook показывают каждый выбранный пункт под шапкой и телом в раскладке обычной страницы. Проверка охватывает обе локали, телефон 360 × 780 и масштаб 2.5. Изолированный пример собирает `Scaffold` с `AppNavigationBar` в нижней области; зависимость от маршрутизатора и хранилища в каталог компонентов не добавлена.

## Известное ограничение: ошибка Flutter при дробной ширине календаря

После посещения каталога дневных выборов и смены локали `get_runtime_errors` зарегистрировал `RenderSliverFixedExtentBoxAdaptor.computeMaxScrollOffset() returned a value that is not an even multiple of its itemExtent`. Ширина страницы — `411.42857142857144`, вычисленная длина прокрутки — `214651748.57010016`; расхождение количества страниц `0.000003228778950870037` превышает `precisionErrorTolerance = 1e-10`. Ошибка относится к `RenderSliverFillViewport` внутреннего `PageView` календаря, а не к панели или её `Hero`.

Причина изолирована отдельной проверкой чистого Flutter без кода приложения и зависимости `table_calendar`. Временный файл `/tmp/task-1-10-sdk-repro_test.dart` запущен через `mise exec --no-deps -- flutter test /tmp/task-1-10-sdk-repro_test.dart`; он завершился отказом с тем же сообщением и теми же числами:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';

void main() {
  testWidgets('дробная ширина и большой индекс PageView не вызывают ошибку', (
    tester,
  ) async {
    tester.view.physicalSize = const Size(1080, 2400);
    tester.view.devicePixelRatio = 2.625;
    addTearDown(tester.view.reset);
    final controller = PageController(initialPage: 105699);
    addTearDown(controller.dispose);
    await tester.pumpWidget(MaterialApp(
      home: PageView.builder(
        controller: controller,
        itemCount: 521723,
        itemBuilder: (_, index) => Text('$index'),
      ),
    ));
    expect(tester.takeException(), isNull);
  });
}
```

Число страниц соответствует существующему диапазону календаря, а ширина — стандартному профилю Pixel 7. В Flutter 3.47.1 проверка находится в `rendering/sliver_fixed_extent_list.dart`, `debugAssertDoesMeetConstraints`; [контракт `computeMaxScrollOffset`](https://api.flutter.dev/flutter/rendering/RenderSliverFixedExtentBoxAdaptor/computeMaxScrollOffset.html) требует точной длины, а [`SliverChildDelegate.estimateMaxScrollOffset`](https://api.flutter.dev/flutter/widgets/SliverChildDelegate/estimateMaxScrollOffset.html) допускает экстраполяцию. Чистый пример подтверждает сбой этой комбинации в SDK.

Обновлять или устанавливать инструменты запрещено условиями стадии. Сужение диапазона дат либо ширины семи колонок изменило бы действующий контракт календаря ради подавления ошибки SDK и не входит в задачу проверки панели. Код приложения и зависимости оставлены без таких обходов.
