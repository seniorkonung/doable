## Проверки контрольной точки

Инструменты использованы в закреплённых версиях без установки или обновления. Каждая команда завершилась с кодом 0.

| Команда | Результат |
| --- | --- |
| `mise run codegen-check` | Повторены локализация, генераторы и снимок Drift v1. Рабочая копия осталась чистой, `pubspec.lock` и generated artifacts совпали с коммитом. |
| `MISE_AUTO_INSTALL=false mise run check` | Форматирование 562 файлов без изменений; проверки области CI успешны; анализатор без замечаний; 4804 проверки приложения и 8 проверок Widgetbook успешны, без пропусков. |
| `MISE_AUTO_INSTALL=false mise exec --no-deps -- flutter build apk --release` | Собран `build/app/outputs/flutter-apk/app-release.apk`, 66.4 MB. |
| `mise exec --no-deps -- openspec validate add-quick-creation-and-persistent-navigation --strict` | Изменение валидно. |

`dtd listDtdUris` не обнаружил работающего приложения или DTD. Контрольная точка использует проверки CLI и сохранённые результаты устройства из 1.10; новой проверки жестов на устройстве здесь не проводилось.

В 1.10 проверены Android 16/API 36 на временном эмуляторе Pixel 7, русский и английский интерфейсы с масштабом 2.5, обычный и предиктивный жесты «назад», системная семантика и Widgetbook в Linux. Документ сохраняет ручное подтверждение пользователя «Я проверил, продолжай». Голосовое озвучивание TalkBack не проверялось. Известная ошибка `PageView` Flutter 3.47.1 при дробной ширине календаря воспроизведена независимо от приложения; она сохраняется. Готовность навигации не означает устранения этой ошибки SDK или отсутствия любых ошибок времени выполнения.

## Границы результата

Контракты `OrdinaryPageScaffold`, `AppNavigation` и затронутые комментарии соответствуют текущей реализации: панель принадлежит каркасу, выбранный пункт — вкладкам оболочки, сброс удаляет историю над оболочкой. Каталог тегов выбирает каркас исчерпывающе по типизированному контексту. Действующие кнопки каталогов и завершение потоков сохраняются в пределах первой фазы.

Сравнение с исходным коммитом первой фазы подтвердило отсутствие изменений кода границы графа, данных и bootstrap, схемы и снимка Drift, зависимостей, Android-конфигурации и правил резервного копирования и переноса. ADR-0020, ADR-0021 и ADR-0022 сохранили статус `proposed`; файлы ADR не изменялись.

Перечитаны `plan.md` и `tasks.md`: фазы уникальны и последовательны от Phase 1 до Phase 3; единственный пакет имеет точный заголовок Phase 1. В этой контрольной точке изменена только отметка 1.11, остальные задачи сохранены побайтно. Следующий этап — отдельная подготовка пакета Phase 2 через `openspec-update-change`.
